> **2026-08-06 新增（用户诉求：提胜率、兼顾轮动、敢追热门但不失控）。**
> 框架有高潮"检测"(Step 2.7)和连板"追踪"(Step 2a)，但**没有把它们合成为一个每日情绪分**，

## 1. 每日情绪温度分（0–100）

**输入全部已可获取**——大部分是 Step 2a（CLS 涨停分析）已经提取的数字，几乎零额外数据成本。

| 子项 | 数据来源 | 权重 | 说明 |
|:---|:---|:--:|:---|
| 广度分（涨停−跌停净家数） | CLS/东财 | 0.20 | 净涨停 ≤−30→0，≥+80→100（线性） |
| 高度分（最高连板） | CLS 涨停分析 | 0.15 | 0板0 / 1板20 / 2板40 / 3板55 / 4板70 / 5板82 / 6板90 / 7+板100 |
| 封板分（封板率%） | CLS | 0.15 | 直接用封板率 0–100 |
| 炸板分（100−炸板率%） | CLS | 0.10 | 炸板率高=分低。炸板率是**退潮先行信号** |
| **赚钱效应分（昨涨停今日均涨幅%）** | 昨日涨停股今日行情 | **0.25** | ≤−5%→0 / 0%→50 / ≥+5%→100。**单一最灵敏指标，权重最高** |
| 情绪面分（涨跌家数比） | 东财/大盘 | 0.15 | 比≤0.33→0 / =1→50 / ≥3→100 |

温度 = Σ(子项分 × 权重)，范围 0–100。`emotion-temp.py` 一键算出并给阶段+建议模式+护栏提示。

> **赚钱效应分是核心**：昨天涨停的票今天平均是红是绿，直接反映"追进去的人赚没赚到钱"。
> 红盘=有人赚钱→敢接力→情绪续；绿盘/大面=昨天追的人被埋→情绪退。比涨停总数更早、更真。

## 2. 六个周期阶段 → 自动模式 + 仓位水位 + 追热门尺度

| 温度 | 阶段 | 自动默认模式 | 仓位水位 | 追热门 | 逻辑 |
|:---:|:---|:---|:---:|:---|:---|
| 0–15 | 冰点/退潮末 | 低估值 / 空仓 | ≤3成 | **禁** | 恐慌未止，超跌不接飞刀 |
| 15–35 | 修复期 | 默认 + 试仓 | 3–5成 | 龙头首板试 | 情绪回暖，小仓试错 |
| 35–55 | 发酵期 | 成长 / 激进并行 | 5–7成 | 敢打低吸 | 赚钱效应扩散，主线在选 |
| 55–75 | 主升期 | **激进为主** | 7–8成 | **大胆追龙头** | 最好赚钱段，敢重仓龙头 |
| 75–90 | 高潮期 | 收（不追跟风） | 开始减 | 只做龙头分歧 | 派发段，追跟风=接盘 |
| 掉头+炸板率↑ | 退潮期 | 防守 | 快速降 | **禁，兑现** | 情绪断裂，先保利润 |

**注意情绪与动作的"反直觉"**：**高潮期温度最高，恰恰要收手**——这是本框架最关键的一条护栏。
温度数字高 ≠ 该更激进；只有 **发酵/主升** 两段才自动放开进攻。

## 3. 自动模式路由（护栏是重点）

接入 **SKILL.md Step 1「大盘环境判断」**（原来只定仓位水位，升级为同时算温度+选模式）。

```
用户"全局选股"(未带模式关键词) 时：
1. 算情绪温度 → 定阶段 → 得 {建议模式, 仓位水位, 追热门尺度}
2. 依次过护栏（优先级高者压过低者）：
   [硬-1] 大盘暴跌规则（大盘单日-1.5%×连续2日）→ 强制"不开新仓/保守"，压过一切温度
          （见 [[大盘暴跌规则]]）
   [硬-2] 账户回撤熔断（-8%降到5成、-12%降到3成）→ 强制保守
          （见 [[资金管理体系]] §4.3）
   [硬-3] 高潮期 / 退潮期 → 禁止自动激进，即使温度数字高（防在派发段自动追高）
   [软-1] 温度较昨日掉头(↓5分+) 且 炸板率↑ → 激进度降一档、仓位水位降一档
3. 显式声明最终姿态（必须输出，让路由透明）：
   "情绪温度 62 / 主升期 → 自动激进模式，仓位水位 7 成 [护栏：无触发]"
   "情绪温度 81 / 高潮期 → 护栏触发(硬-3)：不自动激进，只做龙头分歧回踩，开始减仓"
   "情绪温度 70 / 主升期，但大盘-1.5%×2日 → 护栏触发(硬-1)：强制不开新仓，观望"
```

**核心原则：情绪温度只决定"进攻姿态"，且只在防守条件全部允许时才生效。**
这就是用户要的"**敢冒险但不失控**"——进攻的油门交给情绪周期，刹车永远由暴跌规则/回撤熔断握着。

- 用户仍可用关键词**手动覆盖**自动模式（如硬要"全局选股 激进"）——尊重手动，但若护栏本应拦截，
  须在输出里提示"当前情绪/大盘不支持激进，你手动指定了，风险自负"。
- **手动 > 自动 > 默认保守**：没有任何信号时回落到默认低估值模式，宁可漏不可错。

## 4. 与现有章节的关系（不重复造轮子）

- **数据来源**：广度/连板/封板/炸板全部来自 Step 2a 的 CLS 涨停分析——本文件是**消费**它、合成分数，
  不新增采集步骤。
- **高潮识别**：Step 2.7 用"TOP10 同主题板块数"判高潮（板块维度）；本文件的高潮期用"情绪温度+炸板率"
  判（情绪维度）。两者互为佐证，**同时触发高潮时可信度最高**。
- **追热门的"怎么追"**：本文件只定"该不该激进"；具体到某个热点在其生命周期哪一段怎么进，见
  [[热点参与决策树]]。
- **激进后下多大注**：情绪阶段 → 确定性分层 → 风险预算大小，见 [[资金效率与轮动纪律]] §1。
- **阶段阈值/护栏的校准**：各阶段实测期望由 [[选股台账与胜率归因]] 归因；某阶段系统性负期望
  → 回填本文件护栏降激进度（数据驱动，不拍脑袋）。

## 5. 常见陷阱

| 陷阱 | 纠正 |
|:---|:---|
| ❌ 温度高就无脑激进 | 高潮期温度最高但要收手；只有发酵/主升自动放开 |
| ❌ 只看涨停总数判情绪 | 涨停多但昨日涨停今日全绿=情绪已退。**赚钱效应分优先** |
| ❌ 情绪好就忽略大盘暴跌 | 硬护栏永远压过情绪温度，暴跌日情绪再高也不开新仓 |
| ❌ 路由不透明 | 每次必须输出"温度X/阶段/模式/仓位/护栏状态"，否则用户不知为何这么选 |
| ❌ 炸板率不看 | 炸板率飙升是退潮最早信号，早于涨停家数下降 |
