# 实战案例：2026-06-02 AI算力硬件链主题合成

## 背景
当日市场呈现多板块轮动，但经分析发现多个看似无关的板块共享同一个底层驱动——AI算力需求爆发。

## 主题合成过程

### 当日强势板块清单（从CLS电报提取）
| 板块 | 龙头表现 | 初始归类 |
|:----|:--------|:---------|
| 光纤 | 亨通光电+7%续创新高 | 独立板块 |
| MLCC | 国瓷材料+10%创历史新高 | 独立板块 |
| 超级电容 | 胜业电气30cm涨停 | 独立板块 |
| 绿电 | 韶能股份涨停 | 独立板块 |
| 大消费 | 中央商场3连板 | 无关（排除） |
| 机器人 | 中大力德涨停 | 独立板块 |

### Step 1: 排除无关板块
大消费（零售）是因为618促销+消费刺激，不是AI相关，排除。

### Step 2: 寻找共同驱动
| 板块 | 上涨逻辑 | 底层驱动 |
|:----|:---------|:---------|
| 光纤 | AI数据中心→DCI互联→光纤需求暴增 | ✅ AI算力 |
| MLCC | AI服务器→MLCC用量暴增（高盛研报） | ✅ AI算力 |
| 超级电容 | AI数据中心→供电架构变革 | ✅ AI算力 |
| 绿电 | AI算力中心用电量大增→绿色电力需求 | ✅ AI算力 |
| 机器人 | 宇树科技IPO过会+OpenAI进军机器人 | ❌ 独立题材 |

### Step 3: 排除独立题材
机器人（宇树IPO+OpenAI）是独立的题材炒作，和AI算力硬件链不同，需分开分析。

### 主题确认
```
4个板块 → 1个底层驱动
光纤 + MLCC + 超级电容 + 绿电 → AI算力需求爆发
=> 超级主题：AI算力硬件链
```

### 推荐决策
主题内唯一同时满足"纯正+涨幅温和+位置不高+可上车"的标的是：
**中天科技 600522**（光纤老二，AI光纤逻辑纯正，从高点回调15%后刚企稳）

### 结果验证
推荐时间：10:07 @ 41.15（+1.76%）
随后走势：全天持续拉升到43.29（+9.90%），接近涨停
→ 推荐正确，但进场窗口很窄（约2小时）

### 高潮日确认
14:00后光纤板块4只涨停+1只接近涨停，确认高潮日。
此时该主题的当日进场窗口已关闭。

## 关键学习
1. **10:00-10:30是全市场扫描的黄金窗口** — 此时板块强度已确认但个股还没涨停
2. **主题合成应优先于单一板块分析** — 找到底层驱动后，筛选范围更大、确定性更高
3. **高潮日确认后应立即切换策略** — 从"找标的"转为"等回调"
4. **主题链传导法** → 从最终需求（AI算力）→ 产业链各环节（通信、电容、电源）→ 各环节龙头
