# 多氟多止损二次决策案例（2026-07-06）

## 场景

用户持有 多氟多(002407) 100股 @ 56.25，止损设于52.00元。建仓逻辑：氟化工+氢氟酸涨价催化，60日分位91%（高位建仓）。

## 时间线

| 时间 | 事件 | 价格 | 决策 |
|:----|:----|:---:|:----:|
| 7/3(周五) 收盘 | 跌停后松动，收于49.34 | 49.34 | 等反弹50-52再出 |
| 7/6(周一) 09:47 | 低开高走，从47.53拉回到49.70 | 49.70 (+0.73%) | 等反弹到51-52出 |
| 7/6 盘中 | 冲高至50.90 | 50.90 (+3.2% from开盘) | **用户未操作** |
| 7/6 10:28 | 从50.90回落至48.20 | 48.20 (-2.31%) | 用户问"止损吗" |
| 7/6 上午 | 用户执行卖出 | 47.69 | **亏损-856元(-15.2%)** |

## 教训

**"等反弹"是一个有次数限制的窗口，不是无限期持有理由。** 

止损已破后：
1. 第一次反弹是**最后的出局窗口**，不是"回本的机会"
2. 如果反弹到了目标区间（51-52）附近但用户未操作，且价格再次回落
3. 应**立即切换建议为"马上割"**，不要继续等"下一次反弹"
4. 50.90距51-52目标相差仅0.10-1.10元，应在此提示用户"出或不出，不出就要割"
5. 本例中如果在50.90提醒用户强行出，亏损约-535元(-9.5%)，比最终-856元(-15.2%)少亏321元

## 下次遇到类似场景的Protocol

```python
if 止损已破:
    advice = "等反弹到X-Y区间出"

    if 反弹出现:
        → 明确告知用户："这是最后一次出局窗口，建议现在就挂单"
        → 如果用户没及时操作：
            → 设置观察：如果价格从反弹高点回落>2%，立即改为"割"
    
    if 冲高后再次跌回原低位:
        最终建议 = "立刻割，不要等第二次反弹"
        # 第一次反弹是主力给的逃生机会，第二次反弹大概率不存在
```

## 关键判断框架

| 信号 | 含义 | 应对 |
|:----|:----|:-----|
| 止损已破 | 纪律失守 | 等反弹窗口出局，非持有 |
| 第一次反弹出现 | 最后逃生机会 | 强制出局，不等"再高一点" |
| 反弹失败回落 | 窗口关闭 | 无条件割，不恋战 |
| 仓位极小（<5%账户） | 金额损失有限 | 更应果断割，避免坏持仓占精力 |
