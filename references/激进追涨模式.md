# 激进追涨模式（2026-07-22更新）

## 触发

用户说"全局选股 激进模式"时启用。与默认低PE模式并行运行，分别输出结论。

## 筛选标准

| 条件 | 阈值 | 说明 |
|------|:--:|------|
| 板块ETF涨幅 | >2% | 无板块达标→当日无标的 |
| 个股涨幅 | 3-8% | 已启动未涨停 |
| 放量 | **>2倍5日均量** | K线验证，无量则剔除 |
| PE | 无限制 | 但PE亏损需标注风险 |
| 排除 | ST、次新(<60天) | |

## 四步执行

1. 扫描ETF找涨幅>2%的热点板块
2. 拉板块成分股，筛选涨幅3-8%
3. K线验证放量>2x均量
4. 通过的全部输出，与默认模式结论并列

## 注意

- 无板块>2%或无量达标 → 如实报告"无标的"，不强行推
- 追涨标的止损更紧（-5%），止盈更短（+8-10%）
- 追涨模式不替代默认模式，两者独立运行

## 实例

2026-07-22：仅有色ETF+3.4%，成分股涨幅3-8%但放量均<2x → 无标的。正确结论是"无标的"而非强行推荐。
