# A股数据源可靠性记录

## 可靠（始终可用）

### 腾讯实时行情 (qt.gtimg.cn)
- URL: `http://qt.gtimg.cn/q=<codes>`
- 编码: GBK，需 `iconv -f GBK -t UTF-8`
- 格式: 以 `~` 分隔字段
- 个股: `sz300058` 或 `sh600900`
- 指数: `sh000001`(上证), `sz399001`(深证), `sz399006`(创业板), `sh000688`(科创50)
- **完全可靠，任何时候都能用。作为主力数据源。**

### 腾讯日K线 (fqkline)
- URL: `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=<code>,day,,,<n>,qfq`
- 示例: `sz300058,day,,,20,qfq`
- **字段顺序: 日期, O, C, H, L, V** ← 不是OHLCV！
- 需要 User-Agent header

## 不稳定（经常失败）

### 东方财富 push2 (实时)
- `push2.eastmoney.com` — 经常返回 null (rc:102) 或拒绝连接
- **不要作为主力，只在腾讯数据不够时尝试**

### 东方财富 push2delay (延迟)
- `push2delay.eastmoney.com` — 比push2稍好但仍不稳定
- ETF排名有时可用 (`fs=b:MK0021,b:MK0022,...`)
- 行业板块 (`fs=m:90+t2`) 经常返回null
- 概念板块 (`fs=m:90+t3`) 经常返回null
- 涨幅榜 (`fs=m:0+t6,m:0+t80,m:1+t2`) 经常返回null

### 新浪财经 (hq.sinajs.cn)
- 可以批量查个股，但容易超时
- 格式: `var hq_str_<code>="name,open,prev_close,price,..."`
- 比腾讯慢，作为最后的备选

### CLS财联社
- 多个API端点返回 404/405
- 不可靠，不要依赖

## 降级策略（全局选股时）

```
1. 尝试 ETF排名 (push2delay) → 若成功→过滤A股ETF→拉TOP 5成分股
2. 若ETF排名失败或被港股淹没 → 个股铺面扫描 (腾讯qt 批量40-60只)
3. 个股扫描输出按涨幅排序 → 找3只以上同细分集群 = 确认主题
```
