# 资金效率与轮动纪律（赢面越大下注越大 + 别让钱站岗）

> **2026-08-06 新增。** [[资金管理体系]] 管的是"别亏太多"（按亏损上限反推仓位，防守）；
> 本文件管的是"**赢面大就多下注 + 钱别站岗**"（进攻端的资金效率）。用户诉求：提升资金使用效率。
> 现框架只按风险(亏损上限)定仓，从不按赢面向上放大，也没有回收"占着资金不动"的呆滞持仓的规则。
> 相关：[[资金管理体系]]（风险预算/集中度/回撤熔断）、[[情绪周期与自动模式路由]]（情绪阶段定确定性）、
> [[热点参与决策树]]（追对位置才配加大注）。工具：`templates/portfolio-ledger.py`（🐌呆滞标记）。

## 1. 按确定性/edge 分层加仓（Kelly-lite，在风险预算内向上放大）

**旧做法**：所有交易一律 1.5% 风险预算，不管赢面。**新做法**：**赢面越大，下注越大**——
在 [[资金管理体系]] §1 的框架内，让**风险预算本身随确定性档位浮动**。确定性由三件事合成：

```
确定性 = 情绪阶段(见[[情绪周期与自动模式路由]]) × 主题参与点(见[[热点参与决策树]]) × 席位资金
```

| 确定性档 | 特征（需多数满足） | 单笔风险预算 | 单票上限 | 止损 |
|:--:|:---|:--:|:--:|:--:|
| ⭐⭐⭐ 高 | 主升期 + 启动/发酵期龙头 + 席位机构/知名游资净买 | **2%** | 可用满 30% | ATR 2.5-3× 给趋势呼吸 |
| ⭐⭐ 中 | 发酵期 + 龙二/回踩低吸 + 资金不流出 | **1.5%** | ≤20% | ATR 2× |
| ⭐ 低 | 修复期试仓 / 逆势 / 低情绪 / 靠预测 | **1%** | ≤10% | ATR 1.5× 更紧 |

（整合 [[资金管理体系]] §1 的 1.5%/2% 与 [[quick-rejection]] 成长股确定性分层，成为**单一系统规则**。）

**铁律**：确定性越低，注越小、止损越紧——**不是"看好就重仓"，是"赢面被三重验证了才重仓"**。
高潮期/退潮期即使某票看着强，确定性也自动降档（情绪不支持），不给高档预算。

**用实测校准档位**：哪种 setup/阶段配得上高档预算，由 [[选股台账与胜率归因]] 的期望归因说了算——
某 setup 实测期望显著为正且样本足 → 上调其确定性档；负期望 → 降级。别凭感觉给高档。

## 2. 呆滞资金回收（别让钱站岗）

短线资金的效率 = 周转。**一笔资金卡在不涨不跌的票上 = 效率归零，机会成本巨大。**

### 识别"呆滞短线仓"（🐌）
`portfolio-ledger.py` 已有字段即可判：
```
呆滞 = type为"短线仓"
      且 持有 ≥ N 日（默认 N=5）
      且 浮盈卡在 −3% ~ +3%（不涨不跌）
      且 卡在 20 日区间中位（band 30–70%，非低吸区非高抛区）
      且 跑输所属板块 / 无新催化   ← 此条工具无法自动判，人工确认
```
工具输出加"🐌呆滞"标记列，把候选摆出来；**跑输板块/无催化由人最终确认**。

### 机会成本判据（何时砍呆滞换强势）
```
当出现更强的情绪主升方向（见情绪路由：发酵/主升期新主线）
   且 现金不足以进场
   且 手上有🐌呆滞短线仓
→ 先砍呆滞仓，把资金换到强势方向，而不是硬等呆滞票"解套"
```
机会成本 = 强势方向的预期涨幅 − 呆滞票的预期涨幅（≈0）。**站岗的钱赚的是 0，换过去赚的是主线。**

### 护栏（防与其它模式冲突，关键）
呆滞回收**只针对短线无逻辑站岗仓**，三条线严格分开、不可混用：
- **被套的短线票** → 走纪律止损（逻辑证伪就止损，见 SKILL.md 中线评估铁律），**不是**当呆滞随便砍，
  也不是无脑摊平。
- **长线底仓** → 走 SKILL.md「长线底仓的波段管理（高抛低吸）」，**永远不进呆滞回收**。
- **有催化在酝酿、只是还没启动的短线仓** → 不算呆滞（有逻辑的等待 ≠ 站岗）。

## 3. 资金周转率视角（心法）

- 短线账户的目标不是"持有好公司"，是**让每一笔资金都在做功**。
- 判断持仓时多问一句："这笔钱如果现在换到今天最强的方向，机会成本是多少？"
- 但周转 ≠ 频繁换手——换手要付成本（见 [[交易成本模型]]），只在**机会成本显著为正**时才换，
  不为动而动。呆滞回收是"钱在站岗才换"，不是"每天都要换一遍"。

## 4. 与其它章节的关系（完整资金闭环）

- **买多少（防守下限）**：[[资金管理体系]]——风险预算反推、集中度、回撤熔断。
- **加多大（进攻上限）**：本文件 §1——确定性分层向上放大。
- **钱别站岗（周转）**：本文件 §2/§3——呆滞回收、机会成本。
- **何时走**：[[止盈体系]]——跟踪止盈、分批止盈。
- 四者 + 底仓高抛低吸，构成"方向→仓位→加仓→周转→止盈"的完整资金闭环。

## 5. 常见陷阱

| 陷阱 | 纠正 |
|:---|:---|
| ❌ 看好就重仓（不验赢面） | 赢面要情绪×参与点×席位三重验证，才配高档预算 |
| ❌ 高潮期给强票高档预算 | 情绪不支持时确定性自动降档，不给高档 |
| ❌ 把被套票当呆滞随便砍 | 被套走纪律止损，长线走高抛低吸，别和呆滞回收混 |
| ❌ 为周转而频繁换手 | 换手付成本；只在机会成本显著为正时换 |
| ❌ 死等呆滞票解套 | 站岗的钱赚 0；有更强主线且缺现金时先砍呆滞 |
