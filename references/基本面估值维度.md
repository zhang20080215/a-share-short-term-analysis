# 基本面/估值维度（给纯技术框架补一条安全绳）

> **2026-08-06 新增。** 框架几乎纯技术+板块动量，基本面只有"PE -100~200否决"和"有没有雷"。
> 缺：**财报期规避、历史PE/PB分位(估值锚)、业绩预告扫描**。用户有长线持仓，这些对"拿得住底仓"很关键。
> 定位：**轻量安全绳**，不喧宾夺主——短线仍以板块+技术为主，本维度只做"排雷"和"估值锚定"。相关：[[quick-rejection]]、[[资金管理体系]]。

---

## 1. 财报期规避（最高优先，排雷）

**财报披露窗口是业绩暴雷高发期。** 短线在个股财报披露前后持仓 = 押注不可预判的业绩,违背"激进的保守主义者"的保守。

### A股财报披露时间表
| 报告 | 披露窗口 | 规避动作 |
|:---|:---|:---|
| 一季报 | 4/1–4/30 | 4月下旬对未预告个股降仓/回避 |
| 半年报 | 7/1–8/31 | 8月是雷区高发期 |
| 三季报 | 10/1–10/31 | 10月下旬同一季报 |
| 年报 | 次年1/1–4/30 | 1-4月，叠加**业绩预告**(见第3节) |

**规则：**
- 短线持仓遇个股**财报披露日临近(尤其未预告)** → 降仓或披露后再进,不裸赌业绩。
- 已知业绩确定性高(已预告增长)的可持有;不确定的规避。
- 指数/ETF 无个股暴雷风险,财报期可作为替代持仓工具。

## 2. 历史 PE/PB 分位（估值锚，避免高位接盘）

技术面的"60日分位"看价格位置,**估值分位看贵不贵**——两者互补。
```
PE分位 = 当前PE 在 近3-5年PE区间 中的百分位
  <30%  → 估值低位，安全边际厚（中线加分）
  30-70% → 合理区间
  >80%  → 估值高位，即使技术强也要设紧止损（题材透支）
```
- **短线**：估值分位是**辅助**,不否决强势股,但PE历史高位的题材股给更紧止损。
- **中线/底仓**：估值分位是**核心锚**,>80%分位的底仓考虑高抛(接高抛低吸章)。
- 数据：akshare `stock_a_indicator_lg`(个股历史PE/PB分位) 或东财个股估值页。

> ⚠️ 周期股(煤炭/有色/化工)用PE分位会失真(盈利波动大),改看**PB分位**或价格分位。用户持仓万华(化工)、中国船舶宜用PB。

## 3. 业绩预告扫描（提前排雷 + 找预期差）

A股年报/半年报前有**业绩预告**(预增/预减/扭亏/首亏),是可提前获取的基本面信号。
```
用途一（排雷）：持仓个股出"预减/首亏/业绩暴雷" → 立即评估止损
用途二（预期差）：某股"预增超预期" + 技术刚启动 + 板块配合 → 强信号(如亿纬锂能业绩预增95-110%案例)
用途三（事件驱动归因）：某股突然大涨查不到题材 → 大概率是业绩预告(见"归因分析"事件驱动分类)
```
- 数据：akshare `stock_yjyg_em`(业绩预告)、`stock_yjkb_em`(业绩快报)。
- 时点：预告集中在1月(年报)、7月(半年报)、4月/10月(季报)的中下旬。

## 4. 与框架的整合（在哪一步用，轻量）

```
建仓/持仓评估时，加一道轻量估值+排雷 check（不否决强势技术票，只调风险）：
  ① 财报期临近该股(未预告)？ → 降仓/回避（排雷，优先级最高）
  ② 出过业绩预减/暴雷？      → 剔除或止损
  ③ PE/PB历史分位>80%？      → 可做但止损收紧、仓位减半
  ④ 业绩预告超预期+技术启动？ → 强信号，优先级↑
```
- **不改变"板块+技术优先"的主逻辑**,只在两个地方硬约束：**财报期排雷**(必做)、**已暴雷个股**(剔除)。其余为加减分。

## 5. 常见陷阱
| 陷阱 | 纠正 |
|:---|:---|
| ❌ 财报前裸赌业绩 | 未预告个股临近披露→降仓,不押不可预判的业绩 |
| ❌ 周期股看PE分位 | 周期股盈利波动大,PE失真,改看PB分位或价格分位 |
| ❌ 估值否决强势短线股 | 短线以技术+板块为主,估值只调止损/仓位,不硬否决(否则踏空题材) |
| ❌ 忽略业绩预告的预期差 | 预增超预期+技术启动是强信号,别只当排雷工具 |
