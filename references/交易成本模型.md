# 交易成本模型（把摩擦成本算进盈亏比）

> **2026-08-06 新增。** 框架算盈亏比时基本不扣摩擦成本(印花税+佣金+过户+滑点)。
> 对**高抛低吸/做T**这种小差价高频操作，成本是致命的——一轮0.01-0.03元的差价，扣完成本可能是负的。
> **频繁做T + 不建成本模型 = 用勤奋亏钱。** 相关：[[资金管理体系]]、SKILL.md「做T方法论」、[[lof-trading-costs-analysis]]。

---

## 1. A股交易成本构成（2026现行）

| 项目 | 费率 | 方向 | 说明 |
|:---|:---|:---|:---|
| **印花税** | 0.05% | **仅卖出** | 2023年8月由0.1%下调至0.05% |
| **佣金** | ~0.025%(万2.5) | 买+卖 | 券商而定，**单边最低5元** |
| **过户费** | 0.001% | 买+卖 | 沪深均收 |
| **滑点** | 视流动性 | 买+卖 | 冲击成本，流动性差/大单更高，估0.05-0.2% |

**单边成本率** ≈ 佣金0.025% + 过户0.001% (+滑点)；卖出再加印花税0.05%。
**一轮买卖(round-trip)总成本率** ≈ 佣金0.05% + 过户0.002% + 印花0.05% ≈ **0.10%** + 滑点。

> 经验值：**忽略滑点，一轮买卖约 0.1%**（万2.5佣金）。即 10元的票，一轮成本≈0.01元/股；不含滑点。加滑点保守按 **0.15-0.2%** 估。

## 2. 净盈亏比（替代毛盈亏比）

框架原来的盈亏比是毛的。改为**扣成本后**：
```
净盈亏比 = (目标价 - 入场价 - 单边卖出成本 - 单边买入成本)
         / (入场价 - 止损价 + 双边成本)
```
- 对**中长线**：成本占比小，影响可忽略。
- 对**短线小波段**：目标空间小时，成本会明显压低净盈亏比。目标<3%的交易尤其要扣。

## 3. 做T / 高抛低吸的净边缘检查（最关键）

**做T前必答一句：这个差价扣完成本还剩多少？**
```
每股毛差价 = 卖出价 - 买入价
每股成本   ≈ 买入价 × 0.026%  +  卖出价 × 0.076%   （佣金+过户+印花，不含滑点）
每股净利   = 每股毛差价 - 每股成本
净利总额   = 每股净利 × 股数  -  (若单边佣金不足5元则补到5元的差)

盈亏平衡差价 ≈ 成交价 × 0.1%   （一轮盖住成本所需的最小价差）
```

**规则：**
- 毛差价 **< 盈亏平衡差价** → 这轮做T是**净亏**，不做。
- 10元股：盈亏平衡差价≈0.01元；差价<0.01做了白做。
- 50元股：盈亏平衡差价≈0.05元；用户偏好的"0.01-0.03元差价"在50元票上**扣完成本是负的**，必须放大差价目标。
- **小额做T的隐形杀手**：单边佣金最低5元。买卖各5元=10元固定成本，2000元的小单做T，差价要覆盖10元≈0.5%才不亏。

> **结论：做T的差价目标必须随股价上移。** 低价股(<15元)可做窄差价，高价股(>40元)差价目标至少0.1-0.15元，否则成本吃光利润。
