# 跨会话复盘质疑案例：亿纬锂能 vs 天齐锂业（2026-06-16）

## 场景回顾

**2026-06-12（周五）13:05：** 全局选股推荐了天齐锂业(002466) @ ~62.58 (+2.59%)，逻辑：资源板块全面爆发日（钼+10%、铜+7.5%、黄金+5.8%，TOP 15板块中资源占12席），锂矿是资源线内涨幅最小的子板块（+2.98%），天齐作为锂矿龙头+43亿成交有补涨空间。

**2026-06-16（周二）12:24：** 用户质疑"为什么没选亿纬锂能，而是选了天齐锂业"，此时亿纬锂能(300014) +13.73% 84.9亿成交。

## 核心分析

### 步骤1：定位历史环境

| 维度 | 6/12（决策日） | 6/16（质疑日） |
|:---|:---:|:---:|
| 大盘 | 上证+1.38% 深证+1.66% | 上证+0.06% 深证+1.17% |
| 主线 | 资源（12/15板块） | 半导体链（3/6板块） |
| 天齐归属 | 资源线内补涨标的 | 锂矿（今日+1.76%跟涨） |
| 亿纬归属 | 电池制造（不在主线上） | 电池制造（事件驱动） |

### 步骤2：催化溯源

6/15（周一）盘后，亿纬锂能发布中报预告：
> 亿纬锂能上半年净利同比预增95%—110%

这是6/12无法预见的 **事件驱动型利好**，直接导致6/16跳空高开+13.73%。

### 步骤3：主题驱动 vs 事件驱动

```
6/12 决策时刻：
├─ 资源板块全面爆发 → **主题驱动** ← 可预见
├─ 锂矿是资源线内补涨 → 天齐=合理选择 ✅
└─ 亿纬锂能不在主线上 → 未推荐 ✅

6/15 盘后：
├─ 亿纬锂能业绩+95%-110% → **事件驱动** ← 不可预见
├─ 6/16跳空+13.73% → 意料之外的大涨
└─ 无法在6/12预判
```

## 教训

1. **跨会话复盘质疑不能简单用同日内PK的逻辑处理** — 同日内PK比的是两只候选在当前市场环境下的优劣；跨会话比的是历史决策在历史环境下的合理性
2. **事件驱动的大涨不等于当时选错了** — 业绩预告、大合同、重组等独立利好只能在发布当天知晓
3. **session_search是跨会话复盘的必备工具** — 必须在历史环境下验证决策逻辑，而非在当前环境下重构判断

## 回答模板

当类似跨会话复盘质疑发生时：

```
当时（6/12）选X的原因：
→ X属于今日主线[板块名]
→ X在主线内具备[特征]（涨幅温和/放量/低位置）
→ Y当时[不在主线/无催化信号]

Y后来大涨（[涨幅]%）的原因：
→ Y在[日期]发布了[利好事件]
→ 这是**事件驱动的α**，当时无法预见

结论：当时的推荐基于可预见的主线逻辑，Y的大涨来源于意外利好，非决策失误。
```
