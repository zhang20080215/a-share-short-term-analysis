# 热点参与决策树（敢追，但追对位置）

> **2026-08-06 新增。** 用户要"敢于一定程度冒险追热门票"。但**敢追 ≠ 乱追**——
> 追涨的胜率**几乎完全由"你在主题生命周期哪一段进"决定**：启动期打首板龙头是全市场最高胜率的
> 参与点，高潮期追跟风是全市场最低胜率的接盘点。本文件把散落各处的追涨规则收敛成**一棵按主题
> 生命周期分层的决策树**。主题阶段与 [[情绪周期与自动模式路由]] 的情绪阶段联动。
> 收敛来源：SKILL.md「板块高潮追涨陷阱」「danger-zone 高危区」「追高检查三轴」「主线龙头全涨→扫子板块」、
> [[大阳次日等回踩]]、Step 2a 连板追踪。相关：[[资金效率与轮动纪律]]（追对了下多大注）。

## 核心判据：先定主题在生命周期的哪一段

| 阶段 | 识别信号 | 该怎么追 | 胜率 |
|:---|:---|:---|:--:|
| **① 启动期** | 首板 / 首个放量大阳；板块涨停 **1–2 家**；量比>1，无跟风梯队 | **敢打龙头首板** / 低吸同题材未涨停的趋势股 | ⭐⭐⭐ 最高 |
| **② 发酵期** | 2–3 天；涨停梯队 **3–5 家**；连板高度 2–3 板 | 打**龙二/龙三低位补涨**，或龙头回踩低吸；扫**关联子板块溢出** | ⭐⭐ 中高 |
| **③ 高潮期** | 涨停 **≥5–7 家** / 出空间板(4板+)；涨跌比>5:1；龙头涨停封死 | **不追跟风**；只等次日分歧龙头回踩再进 | ⭐ 低（跟风=接盘） |
| **④ 退潮期** | 炸板率升 / 连板断 / **昨日涨停今日翻绿** | **只出不进**，兑现利润 | ✗ 负期望 |

> 与情绪温度联动：主题阶段 ≈ 整体情绪阶段的局部投影。整体主升期 + 某主题启动期 = 最强组合；
> 整体高潮期 + 某主题高潮期 = 最危险，坚决不追。

## 写死的胜率杠杆（这几条是"敢追但追对"的关键）

1. **打首板龙头 > 追高潮跟风。** 同样是"追"，胜率天壤之别。首板龙头有想象空间、次日溢价高；
   高潮期跟风股买不到龙头才去买的"第二梯队"，分歧日**最先被杀**。**敢冒险要冒在启动期，不是高潮期。**
2. **龙头 > 跟风（强化 SKILL.md 板块优先 §3）。** 同板块内宁选龙头稍高位置，不选跟风更低位置。
   跟风的"更低价"是假安全边际，退潮时跌得比龙头快。
3. **首阴反包 / 首次分歧低吸 = 高胜率二次上车点。** 龙头连板后第一次放量分歧（首阴），
   若次日能反包，是错过首板后**胜率仅次于首板**的介入点。
4. **涨幅区间（承接 danger-zone）**：1–4% 是"刚启动"敢打，5–7% 是"高危区"（冲完一波未涨停=日内高点），
   **不追 5–7%**。优先 2–4% 温和启动。
5. **大阳次日等回踩（承接 [[大阳次日等回踩]]）**：单日 +5% 以上次日高概率无法延续，约 50% 概率
   回踩 1–3%。除非首板龙头当日打，否则默认等次日回踩不追当日大阳。

## 追高检查三轴（收敛自 SKILL.md「追高检查」，此处为单一出处）

用户问"还能进吗/还能追吗"（对当日已推荐/讨论过的票，价格已涨）时：

```
score = 0
# 轴1 时间：早盘(9:30-10:30)且涨幅<5% → +1；午盘/尾盘 → -1
# 轴2 价格：涨幅<3% → +1；3-6% → 0；>6% → -2
# 轴3 板块：板块涨停≥3(高潮) → -2
```
| 评分 | 判断 |
|:--:|:---|
| ≥+2 | ✅ 还可进，给买入区间 |
| 0~+1 | ⚠️ 分批（现价一半，回调再一半） |
| ≤−1 | ❌ 窗口已过，等明天/回调 |
| 板块高潮日 | ❌ 强制不追 |

**可追的特例（低开 V 反）**：①开盘跌>2% ②从最低已拉回3%+ ③放量 → 低开给上车机会，V反确认方向，可追。

## 主线龙头全涨过头 → 扫关联子板块（收敛自 SKILL.md，此处为单一出处）

主线板块龙头全 ≥7% 买不进时，**不要放弃这个大方向，扫它的关联子板块**（资金溢出接力）：
- CXO → 减肥药/GLP-1、创新药、医疗器械、医药流通
- 半导体 → 封测、设备、材料、EDA
- AI → 光模块、服务器、应用、机器人
- 新能源 → 光伏/储能/风电/电网

关联子板块龙头在 0–4% 区间是**可接受的替代方案**（主线溢出+补涨），不是"退而求其次"。

## 常见陷阱

| 陷阱 | 纠正 |
|:---|:---|
| ❌ 高潮期追跟风"补涨" | 高潮期第二梯队=接盘，分歧日最先被杀。只等次日龙头回踩 |
| ❌ 把"敢冒险"用在错误阶段 | 敢冒险=启动期打首板龙头，不是高潮期追高 |
| ❌ 龙头买不起就买跟风 | 换板块/换关联子板块，不降级买弱势跟风（假安全边际） |
| ❌ 追当日大阳不等回踩 | 除首板龙头外，+5%大阳默认等次日回踩 |
| ❌ 退潮期还想抢反弹 | 炸板率升/昨涨停今绿=只出不进，先保利润 |
