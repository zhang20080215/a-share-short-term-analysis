# 2026-07-02: "不用一直推全新，推最佳" — 多轮全局选股的第二次修正

## 现象

同一次会话中用户连续4+次要求全局选股。各轮推荐：
1. 防守+处理止损（未买入）
2. 沈阳机床（工业母机）→ 用户未确认
3. 紫金矿业（贵金属）→ 用户未确认
4. 五洲新春（机器人建仓方案）→ 用户未确认
5. 中国中车（交运设备）→ 用户问了一句但没买
6. 用户最终买了多氟多（氟化工，自己选的）

用户在4次新方向推荐后说：**"不用一直推全新，推最佳"**

## 根因

虽然2026-07-01已修订"不用强制换方向"，但SKILL.md中仍然有一条硬规则：
> 连续3次'全局选股'请求后，推荐必须与第一次完全不同

这条导致"为了不同而不同"：
- 第1次：防守（没买）
- 第2次：工业母机（没买）
- 第3次：**强制切换到** 贵金属（紫金矿业）—— 其实工业母机当天仍然强势（+5.24%）
- 第4次：**强制切换到** 交运设备（中国中车）—— 但其实不如紫金矿业信号强
- 用户感觉我在循环推不同方向，而不是坚定地告诉我"哪个最好"

真实情况：用户不是在否定方向，而是在**比较和犹豫**。每次推新方向反而让ta更犹豫。

## 修正

### 核心原则：一致性胜于新颖性

重复全局选票时，不是"换方向展示多样性"，而是"用更新后的数据强化最佳选择的确定性"。

### 新决策树（2026-07-02+）

```
第N次全局选股请求（N≥2）
├─ 先检查用户有没有买之前的推荐
│  ├─ 如果买了 → 检查持仓情况，是否需要调整
│  └─ 如果没买 → 不是否定方向，是还没决定
├─ 刷新数据
├─ 把所有已推荐的方向做成一张对比表
├─ 用当前最新数据判断哪个方向信号最强
│  ├─ 原方向仍然最强 → 坚定推荐原方向，可以调整具体标的
│  └─ 新方向明显更强 → 用数据对比说明为什么，而不是突然切换
└─ 输出时只说"这是基于当前数据的最佳选择"，不说"这是新方向"
```

### 三次以上的特殊规则

- **去掉"三次后必须完全不同"的硬规则**
- 替代规则：三次以上时，用**全量PK表**对比所有已推过的方向，给出排名
- 如果所有方向都已推荐过且原方向仍最优，就说"还是XX，因为数据没变"
- 用户真正要的是确定性，不是多样性

### 用户偏好（嵌入技能）

本用户在反复选股时偏好：
- ✅ 直接给一个最佳答案，对比表辅助，不循环推新
- ✅ 用数据说话：哪个板块最强+位置最低+放量最大
- ❌ 不要为了"不重复"而推次优标的
- ❌ 不要每次请求都换方向
