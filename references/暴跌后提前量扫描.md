# 暴跌后提前量扫描：看下周，不是今天

## 适用场景

大盘单日跌幅>3%（创业板/科创50>5%），全市场恐慌时，需要找下周反弹方向。

## 核心原则

暴跌日的"今天什么强"没有参考价值——涨的都是防御板块（电力/银行/高股息），下周反弹时它们反而会补跌。

**真正有价值的是：什么跌透了、什么资金没跑。**

---

## 暴跌后三类"下周启动"信号

### 1. 超跌缩量 ⭐⭐⭐（最强反弹信号）

**识别：** 板块ETF从10日高点回撤>20% 且 今日量比<0.7 且 10日分位<5%

```
例：2026-07-17 半导体ETF: 回撤-25.8% + 量比0.6x + 分位3%
```

**逻辑：** 跌到没人卖了=恐慌耗尽。卖盘枯竭后，一点买盘就能拉起来。

**验证指标：**

| 信号 | 阈值 | 含义 |
|------|:--:|------|
| 回撤幅度 | >20% | 跌透了 |
| 量比 | <0.7x | 卖盘枯竭 |
| 分位 | <5% | 地板价 |

### 2. 蓄力形态没被大盘打散 ⭐⭐⭐

**识别：** 之前形成"大阳次日缩量蓄力"或"暗吸"形态的个股，今天虽然跌但跌幅远小于板块。

```
例：2026-07-17 三七互娱: 7/15大阳+4.8%→7/16缩量→7/17创业板-5.55%仅跌-1.99%
```

**逻辑：** 主力在护盘，蓄力形态没被大盘打散=大盘企稳后会率先上攻。

**验证：** 个股跌幅 < 创业板跌幅 × 0.5（即超额>2.5%）

### 3. 板块ETF龙头被错杀 ⭐⭐

**识别：** 板块暴跌但PE最低的龙头跌幅小于板块平均

```
例：2026-07-17 创新药ETF-7.06%，药明康德PE18仅跌-6.54%
```

**逻辑：** PE低的龙头有基本面兜底，跟跌是被板块拖累不是自身问题，反弹时领涨。

## 暴跌后操作时间表

| 时间 | 动作 |
|------|------|
| **暴跌当天（周五）** | 不做任何操作。扫描超跌板块+抗跌个股，列候选池 |
| **暴跌次日（周一）上午** | ⛔ 不买。还有惯性下杀 |
| **暴跌次日（周一）下午** | 观察：创业板是否不再创新低？成交量是否缩量？ |
| **暴跌第三日（周二）** | 确认企稳信号后动手（三条件：不创新低+缩量+目标ETF翻红） |

**铁律：暴跌后的真正买点在第3-4天，不在第2天。**

---

## 致命反例

| 错误操作 | 为什么错 |
|------|------|
| 暴跌当天抄底 | 第二天还有惯性下杀，抄在半山腰 |
| 买防御板块（电力/银行） | 反弹时资金从防御撤出，防御补跌 |
| 追当天+5%以上的"逆势股" | 可能是拉高出货（哈药+3.85%换手29.5%） |
| 买炸板的涨停股 | 封不住=主力也在出货（九安医疗79→78） |

## 2026-07-17 实战案例

**大盘：** 创业板-5.55%，科创50-5.09%，深证-4.31%
**场景：** 科技连崩第4天，全市场4红/35绿

**扫描结果：**

| 信号类型 | 标的 | 数据 | 下周判断 |
|------|------|------|------|
| 超跌缩量 | 半导体ETF | 回撤25.8% 量比0.6x 分位3% | 🥇 反弹弹性最大 |
| 蓄力没散 | 三七互娱 | PE13 -1.99% vs 创业板+3.6%超额 | 🥈 主力护盘 |
| 龙头错杀 | 药明康德 | PE18 -6.54% vs 创新药-7.06% | 🥉 基本面兜底 |
| 炸板出货 | 九安医疗 | +8.78% 分位96% 炸板 | ❌ 不碰 |
| 妖股出货 | 哈药集团 | +3.85% 换手29.5% | ❌ 不碰 |

**关键教训：**
- 早盘09:32 AI应用概念+1-3% → 收盘全绿-2~-5%。开盘冲高是假动作。
- 蓝色光标09:32 +3.1% → 收盘-5.2%。全天振幅8.7%。
- **暴跌日开盘数据完全不可信，必须等30分钟以上。**
