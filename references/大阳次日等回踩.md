# 大阳次日等回踩——入场时机模式

## 模式描述
当一个股票单日涨幅超过+5%时，次日高概率出现回踩（1-3%的回调），提供更好的入场点。

## 数据支撑（基于本会话实测）

| 标的 | 大阳日 | 涨幅 | 次日表现 |
|------|------|------|------|
| 泡泡玛特 05/29 | +7.2% | 06/01 +2.3%（涨但减速） |
| 泡泡玛特 05/08 | +3.1% | 05/11 **-1.4%** |
| 泡泡玛特 07/08 | +2.5% | 07/09 **-2.1%** |
| 泡泡玛特 06/26 | +2.9% | 06/29 平盘 |
| 恺英网络 07/15 | +10.7%（涨停） | 07/16 +0.1%（涨停后横盘） |
| 小米 07/08 | +7.7% | 07/09 **-1.7%** |

**规律**: 大阳次日，约60-70%的概率无法延续同等涨幅，至少50%概率出现回踩。即使是趋势强劲的牧原（07/15 +5.1%→07/16 +3.2%），次日涨幅也明显衰减。

## 适用条件

**应该等的场景：**
- ✅ 单日涨幅+5%以上
- ✅ 中线建仓（不在乎1天差价）
- ✅ 标的处于底部反转初期（第一根大阳）
- ✅ 日线已有明显上影线（尾盘回落）
- ✅ 大盘环境弱势（大阳股容易被大盘拖累回踩）

**不应该等的场景：**
- ❌ 连续涨停的妖股（等不到回踩）
- ❌ 明确的重大利好（如财报超预期+50%）
- ❌ 板块全面涨停潮中的龙头（次日直接一字）
- ❌ 日线实体饱满无上影+放量突破关键阻力（可能加速）

## 操作细则

### 等回踩的标的
```
明日开盘后操作：
- 开盘低于今日收盘1-2% → 直接分批建仓
- 开盘平开/高开 → 等30-60分钟，看方向
- 开盘继续冲高 → 放弃，不追
- 开盘跌破今日低点 → 重新评估，可能趋势转弱
```

### 不等回踩的标的（直接追）
```
满足以下3个以上条件可追：
1. 突破关键中期阻力位（如60日均线、前高）
2. 成交量是前日2倍以上
3. 板块内多只股票同步涨停
4. 有明确的重大催化剂
5. 日线几乎无上影线（收盘=最高）
```

## 与板块高潮规则的关系

- **板块高潮**（涨跌比>5:1）→ 不追，等次日分歧（本技能已有规则）
- **个股大阳**（单只+5%+但板块未高潮）→ 等次日回踩（本规则）
- **个股涨停+板块未高潮** → 判断次日是否连板潜力，有则追，无则等

两条规则的共同逻辑：**不在情绪最热的时候入场。**
