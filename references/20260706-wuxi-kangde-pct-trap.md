# 2026-07-06 药明康德："涨幅最小≠还有空间"教训

## 场景
7/6 医药CRO主线全面爆发（CRO+4.47%, 创新药+3.75% 10涨停）。
泰格医药+4.58%, 信立泰+3.84%, 康龙化成+6.32%。
药明康德仅+2.83%，被我判断为"涨幅最小有补涨空间"并推荐。

## 关键遗漏：60日分位
**药明康德 60日分位 = 85.2%（高位）** 完全没有检查。
用户立即指出"数据是不是拿错了"。

## 根因分析
1. **注意力偏差** — 看到医药板块太热，急于在同主题内找标的
2. **替代指标替代** — 用"当天涨幅最小"替代了"60日位置低"，以为涨幅小=没涨过
3. **数据检查不完整** — 检查了当天K线蜡烛（上影1%✅）但忽略了更基础的60日位置指标
4. **午后数据过期** — 11:49看的+2.83%，到13:00后跌到-0.77%

## 正确做法
```python
if 候选股 in 热点板块:
    必须同时评估：
    □ 今天涨幅（大小决定追高风险）
    □ 60日分位（<70%才可推荐，<50%为佳）
    □ 今天上影比例（<40%才可推荐）
    □ 数据时效（>15分钟需重拉）
    
    if 今天涨幅最小 and 60日分位>70%:
        # 这是个假信号！它涨得少不是因为"还没涨"，而是因为它已经在高位了
        放弃该候选，换同主题不同细分方向
```

## 更好的选择对比
| 候选 | 60日分位 | 当天涨幅 | 推荐？ |
|:----|:-------:|:-------:|:-----:|
| 泰格医药 | 51.5% | +4.58% | ✅ 位置好，涨幅合理 |
| 药明康德 | **85.2%** | +2.83% | ❌ 高位，涨幅假象 |

## 教训总结
**"今天涨幅最小"是一个危险的有偏指标——它完全可能因为股票已经在高位（接近60日高点）所以涨不动了。**
必须先查60日分位。60日分位>70%的标的无论如何都不推荐，即使它今天只涨了1%。
