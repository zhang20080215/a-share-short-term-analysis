# 龙虎榜与席位分析（短线最大的信息边缘）

> **2026-08-06 新增。** A股短线本质是**游资博弈**。框架此前讲连板、讲主力资金net(东财fflow)，
> 但完全没有**龙虎榜(席位)**——知道"哪个知名游资/机构席位在买"，比看板块涨幅有用得多。
> 这是一整块缺失的 alpha 来源。相关：[[api-patterns]]、SKILL.md「Step 2a 连板龙头追踪」。

---

## 0. 为什么龙虎榜是短线的核心信息

盘面只告诉你"涨了"，龙虎榜告诉你"**谁买的、买了多少、是不是能持续的钱**"。同样一个涨停：
- 知名游资/机构专用席位大买 → 有主导资金，次日有承接
- 纯量化席位/一日游席位 → 打板资金，次日大概率兑现走人
- 机构专用净卖出 → 涨停是散户情绪，机构在出货 = 陷阱

**用途：验证"这波谁在买"，区分真突破 vs 情绪一日游。**

## 1. 席位类型识别（读懂买卖前五）

| 席位类型 | 含义 | 信号 |
|:---|:---|:---|
| **机构专用** | 公募/保险等机构 | 净买=中线资金认可(强)；净卖=机构出货(弱) |
| **知名游资席位** | 章盟主、赵老哥、方新侠、量化大厂等(按营业部名) | 净买=题材有龙头资金主导，有持续性 |
| **沪/深股通专用** | 北向资金 | 净买=外资认可，偏中线 |
| **拉萨/量化席位** | 东方财富拉萨系、量化打板 | 打板资金，追涨快撤也快，次日风险高 |
| **普通营业部** | 散户聚集 | 参考价值低 |

> 席位名单会变，不要硬编死名字。**看"机构专用/知名游资净买"这类可判定的信号，而不是记具体营业部名。**

## 2. 关键读数

```
① 龙虎榜净额(BILLBOARD_NET_AMT)：买五合计 - 卖五合计
   > 0 且占成交额比例大 → 有资金主导
   < 0 → 上榜是抛压，涨是散户情绪

② 买卖前五结构：
   - 买一远大于其余 → 单一主力控盘(强，但也集中)
   - 买五分散 + 机构占多席 → 合力做多(健康)
   - 卖方有机构专用 → 机构在派发(警惕)

③ 上榜原因(EXPLANATION)分类：
   - 连板/涨停偏离 → 强势股，看谁在接力
   - 换手率异动 → 游资博弈激烈，波动大
   - 严重异常波动 → 监管关注，风险信号
```

## 3. 与框架的整合（在哪一步用）

**接 SKILL.md「Step 2a 连板龙头追踪」之后，加一道席位验证：**
```
Step 2a 提取当日焦点股/连板龙头
   ↓
对焦点股拉龙虎榜(如已上榜)：
   ├─ 机构/知名游资净买 → 该方向资金主导确认，优先级↑
   ├─ 纯量化打板席位 → 一日游概率高，不追高
   └─ 机构专用净卖 → 涨停是情绪，剔除
   ↓
用席位结论修正 SKILL.md 的选股优先级
```

**归因分析(为什么涨)时**：龙虎榜是"谁买的"的直接证据，比猜催化更硬。

## 4. 数据获取（工具 templates/lhb-fetch.py）

- **Hermes 首选 akshare**：
  - `ak.stock_lhb_detail_em(start_date, end_date)` — 当日龙虎榜列表
  - `ak.stock_lhb_stock_detail_em(symbol, date, flag)` — 单只的买卖席位明细
- **降级：东财 datacenter API(curl，已验证可达)**：
  ```
  https://datacenter-web.eastmoney.com/api/data/v1/get
    ?reportName=RPT_DAILYBILLBOARD_DETAILSNEW
    &columns=SECURITY_CODE,SECURITY_NAME_ABBR,TRADE_DATE,EXPLANATION,BILLBOARD_NET_AMT,ACCUM_AMOUNT
    &filter=(TRADE_DATE='YYYY-MM-DD')
    &sortColumns=BILLBOARD_NET_AMT&sortTypes=-1&pageSize=50&source=WEB&client=WEB
  ```
  字段：BILLBOARD_NET_AMT=龙虎榜净额，ACCUM_AMOUNT=成交额，EXPLANATION=上榜原因。

## 5. 常见陷阱

| 陷阱 | 纠正 |
|:---|:---|
| ❌ 只看涨停不看谁买 | 涨停+机构净卖=陷阱，必须看席位 |
| ❌ 记死游资营业部名字 | 席位会变，看"机构专用/知名游资净买"信号，不背名单 |
| ❌ 龙虎榜净买就无脑追 | 还要看买一是否过度集中(单一控盘次日易砸)、是不是量化打板 |
| ❌ 龙虎榜是T+1数据 | 龙虎榜收盘后出，是**次日**决策的验证，不是盘中实时信号 |
