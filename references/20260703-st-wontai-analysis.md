# *ST闻泰（600745）深度分析案例

**日期：** 2026-07-03
**场景：** 用户主动问"ST闻泰" → "做深入分析"
**用途：** 作为 `references/st-stock-policy-framework.md` 的实战案例参考

---

## 公司背景

闻泰科技原是千亿级ODM+半导体IDM龙头，核心资产为**安世半导体（Nexperia）**——全球汽车功率半导体龙头。2025年因安世境外控制权丧失+业绩巨亏+审计非标被实施退市风险警示（\*ST）。

## *ST原因（三要素）

| 原因 | 说明 |
|:----|:------|
| 核心资产失控 | 安世半导体境外控制权丧失，不再并表，引发巨额资产减值 |
| 2025年巨亏 | 减值+主业下滑，触发净利润为负+营收不足的\*ST条件 |
| 审计非标 | 财务报告被出具无法表示/否定意见 |

## 退市风险量化评估

| 维度 | 数据 | 风险结论 |
|:----|:----:|:--------|
| 股价 | **18.25元** | ✅ 无面值退风险（安全线1元以上） |
| 市值 | **232亿** | ✅ 无市值退风险（安全线3亿以上） |
| 净资产 | 约**230亿**（PB≈1） | ✅ 净资产为正，是最关键的缓冲 |
| PE(动) | **-2.53**（亏损中） | 🔴 仍在亏损，摘帽需2026年扭亏 |
| ST涨跌幅 | ±5%（若改10%则波动翻倍） | ⚠️ 政策变化中 |

**结论：短期退市风险低。** 无面值退、无市值退、净资产为正——即使亏损也不会马上退市。关键是2026年年报能否扭亏+审计标准无保留。

## 摘帽博弈分析

### 有利因素 ✅
- 已完成亏损业务剥离，聚焦功率半导体
- 境内半导体主业保持稳定盈利
- PB≈1（破净边缘），摘帽后PB修复空间大（1.0→1.5=+50%）
- 股价18元远离面值，无退市紧迫性
- 尾盘异动（14:25放量拉升至18.36接近涨停）→ 有资金博弈周末/政策

### 不利因素 ❌
- PE为负，仍在亏损，摘帽需等2026年年报（至少2027年4月前）
- 安世失控的实质影响未完全消化
- 机构被动清仓压力（很多机构不能持有ST股）

**解读：** 尾盘30分钟集中放量，占全天成交的40%+。通常是博周末消息或政策变化的资金行为。

## 核心矛盾

```
安世半导体失控（减值）→ *ST → 股价暴跌60%
         ↓
剩余业务（境内功率半导体）是否值230亿？
         ↓
PB≈1 = 市场认为值这个价
         ↓
摘帽关键：2026年能否靠境内半导体扭亏（哪怕5-10亿利润）
```

## 实用规则提炼

| 规则 | 说明 |
|:----|:------|
| \*ST股无面值/市值退风险 ≠ 安全 | 核心是净资产和盈利能力，不是股价远离1元就够了 |
| PB≈1不一定便宜 | 如果资产质量差（商誉高/坏账多），破净也不安全 |
| 尾盘异动=有资金博弈 | \*ST股流动性差，尾盘集中放量常是资金提前布局周末催化 |
| 摘帽距离 | 至少要等下一个年报（\*ST后最快一年），别期望短期反转 |
