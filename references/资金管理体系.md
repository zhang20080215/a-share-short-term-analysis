# 资金管理体系（第二支柱·核心）

> **2026-08-06 新增。** 本框架的选股(进攻)很强,但资金管理(防守)长期缺失。
> **长期盈利 = 选股 × 风控,是乘法不是加法。** 本文件是"防守"这个乘数的核心。
> 相关：[[止盈体系]]（何时走）、SKILL.md「长线底仓的波段管理」（底仓波段）、[[api-patterns]]（数据）。

---

## 0. 核心转变：仓位由"风险"反推，不由"感觉"拍

**旧做法（错的）：** 先拍一个仓位百分比(25%/40%/满仓),再谈止损。
**新做法（对的）：** 先定每笔能亏多少钱(风险预算)+止损距离 → **反推**该买多少。

> **止损远的票买少，止损近的票买多。** 这样每笔的最大亏损是恒定的,和标的波动无关。
> 现框架"现金充裕就上25-40%"是反的——它让高波动票也上重仓,一次止损就伤筋动骨。

---

## 1. 单笔风险预算（Risk Per Trade）

**铁律：每一笔交易，最大可承受亏损 = 账户总值的 1-2%。**

| 账户 | 单笔风险预算(1%) | 单笔风险预算(2%激进) |
|:---|:---|:---|
| 20 万 | 2,000 元 | 4,000 元 |

- **保守的激进主义者**取值：常规仓 1.5%(3,000元),高确定性主升浪龙头可放到 2%(4,000元),试仓/逆势 1%(2,000元)。
- 这是**单笔**上限,不是总仓。同时持有多笔时见第4节组合层控制。

---

## 2. 仓位公式（由止损距离反推股数）

```
止损距离% = (入场价 - 止损价) / 入场价
仓位金额  = 单笔风险预算 / 止损距离%
建议股数  = ⌊ 仓位金额 / 入场价 / 100 ⌋ × 100   （向下取整到100股）
实际风险  = 建议股数 × (入场价 - 止损价)          （复核 ≤ 风险预算）
```

**示例（账户20万，风险预算1.5%=3,000元）：**

| 标的 | 入场 | 止损 | 止损距离 | 仓位金额 | 建议股数 | 实际最大亏损 |
|:---|:---|:---|:---|:---|:---|:---|
| A(低波动) | 20.0 | 19.4 | 3.0% | 3000/3% = **10万** | 5000股 | 3,000元 ✓ |
| B(高波动) | 55.0 | 50.5 | 8.2% | 3000/8.2% = **3.66万** | 600股 | ~2,700元 ✓ |

**关键读法：** 同样3000元风险预算,低波动A能上10万仓,高波动B只能上3.6万仓。**波动越大,仓位自动越小**——这正是风险预算的意义,替代了"拍百分比"。

**仓位金额还要同时受第3节的绝对上限约束**（取两者更小值）。

---

## 3. ATR 自适应止损（替代固定3-5%）

**问题：** 现框架"止损3-5%"是固定比例。一只日振幅7-11%的票(如南大光电),3%止损=每天被正常波动扫出局。
**解法：** 止损距离按标的自身波动率(ATR)定,而不是一刀切。

```
ATR(14) = 最近14日 TrueRange 的均值
  TrueRange = max( 当日高-当日低,
                   |当日高 - 昨收|,
                   |当日低 - 昨收| )

止损价 = min( 入场价 - 2×ATR(14),      # 波动率止损
              最近有效支撑位下方 )        # 结构止损
      取更近(更高)的一个 = 更早保护
```

- **2×ATR** 是常规系数;试仓/超高波动可用 1.5×ATR(更紧),主升浪趋势票可放 2.5-3×ATR(给趋势呼吸空间)。
- 算出止损价后 → 回到第2节反推股数。**止损与仓位是一体的**:ATR大→止损远→股数少。
- 工具：`templates/atr-stop.py`(Hermes运行) 一键输出 ATR、建议止损价、建议股数。

## 4. 组合层控制（单票 / 板块 / 相关性 / 回撤）

单笔管好了,还要管组合整体,避免"每笔都合规,合起来是满仓单一beta"。

### 4.1 集中度上限
- **单票 ≤ 30%** 账户市值。
- **单一板块/同beta ≤ 50%** 账户市值(如半导体链的封测+材料+设备合计算一个beta)。
- 突破上限即使信号再好也不加,换低相关方向。

### 4.2 组合相关性检查（推荐/加仓前必做）
```
新增标的前，检查它与已有持仓的相关性：
  ├─ 同细分方向(如都封测) → 拒绝，见 SKILL.md Step3 "持仓方向去重"
  ├─ 同大主题不同细分(如封测+材料) → 计入同板块50%上限
  ├─ 同宏观beta(如都强周期/都成长) → 提示集中，降低新仓规模
  └─ 低相关(如公用+军工+化工) → ✓ 真分散，正常规模
```
> 用户当前持仓(长江电力·公用 / 中国船舶·军工 / 万华化学·化工)是低相关的好例子。

### 4.3 账户级回撤熔断（Drawdown Circuit Breaker）
以**账户峰值净值**为基准计回撤:

| 账户回撤 | 强制动作 |
|:---|:---|
| **-8%** | 总仓位降到 5 成以下,暂停开新仓,只做减仓/防守 |
| **-12%** | 总仓位降到 3 成以下,进入冷静期,复盘后再重启 |
| 单日 -5% | 当日不再开新仓,收盘后强制复盘 |

- 这是账户级的保险丝,独立于单票止损。扩展自"同日多笔止损降级"规则。
- 熔断期间**只减不加**,直到净值企稳/复盘完成。

## 5. 可执行性检查（迁移自旧碎片，保留）

### 5.1 可买手数对齐（AVAILABLE CASH ALIGNMENT）
```python
max_shares = int(available_cash / (price * 100)) * 100  # 100的倍数
max_hand   = max_shares // 100
```
- max_hand < 1 → 太贵买不起,换标的。
- 但注意：**最终股数以第2节风险反推为准**,可买手数只是"买得起吗"的天花板,不是"该买多少"。9.75元能买34手 ≠ 就该买34手。

### 5.2 多票同时建仓的预算分配（MULTI-STOCK BUDGET SPLITTING）
```
① 每只先按第2节算"风险反推股数"
② 各只仓位金额加总，若 > 可用现金 → 按信号强度加权缩减
③ 每只向下取整到100股，保留 5-20% 现金做低吸备用
④ 单票/板块不得突破第4.1节上限
```
输出表格：

| 标的 | 股数 | 金额 | 仓位% | 止损 | 止盈 | 单笔风险 |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| … | ##手 | ¥### | ##% | ¥## | ¥## | ¥#### |
| 备用现金 | — | ¥### | ##% | — | — | — |

> ⚠️ 旧的"现金充裕就上25-40%"规则**已废止**——仓位由风险预算+止损距离决定,不由现金多少决定。现金多只是允许更多笔/更大的绝对仓,不改变单笔的风险上限。

## 6. 选股流程的硬前置（写入检查清单）

**给任何买入推荐前，必须完成这三步,缺一步即视为流程未完成：**
```
□ 定风险预算（账户×1-2%）
□ 定止损价（ATR自适应 或 支撑位下方）→ 得止损距离
□ 反推股数（风险预算/止损距离）→ 复核不破单票/板块/回撤上限
```
输出推荐时必须带上"单笔风险 ¥XXXX(账户X%)",让风险显式可见。
