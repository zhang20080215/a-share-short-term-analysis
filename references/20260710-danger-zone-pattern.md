# 5-7%涨幅高危区模式（2026-07-10 识别）

## 现象

一天内四只推荐全部在推荐后回落：

| 推荐 | 时间 | 推荐时涨幅 | 后续 | 上影 |
|------|------|----------|------|------|
| 亨通光电 600487 | 09:44 | +5.41% | → 80.21 (+0.19%) | 90.3% |
| 九洲药业 603456 | 10:52 | +6.52% | → 14.60 (+4.66%) | 31.9% |
| 沃森生物 300142 | 12:42 | +6.72% | → 13.01 (+4.08%) | 31.4% |
| 航天彩虹 002389 | 13:27 | +6.19% | → 18.58 (+4.62%) | 21.5% |

用户质问："为什么今天的三只推荐票，都在你推荐后下落"

## 根因

**涨幅5-7%是"高危区"**——刚好处于"已经冲了一波"和"还没涨停"之间，是日内冲高回落的起点。

框架中有"刚启动 > 蹲底部"的原则，但**6%不是"刚启动"，是"刚结束"**。

## 涨幅区间重新分级

| 涨幅区间 | 名称 | 风险 | 推荐策略 |
|---------|------|------|---------|
| 0-1% | 未启动 | 可能不涨 | 仅在板块极强+刚突破时考虑 |
| **1-3%** | **温和启动** ⭐ | **最佳买点** | 板块确认后优先选这个区间的 |
| **3-4%** | **确认启动** ✅ | 低 | 安全边际仍够，可重仓 |
| 4-5% | 加速中 | 中等 | 需蜡烛极干净+分位<50% |
| **5-7%** | **高危区** 🔴 | **极高** | **除非上影<15%+分位<40%+板块刚爆发，否则不碰** |
| 7%+ | 追高 | 否决 | 自动排除 |

## 轮动过快日检测

当天三个主题（半导体→CRO→航天）均在一小时内爆发又回落。特征：
- 大盘偏弱（创业板-0.9%）
- 每个新主题爆发时，板块龙头涨停/大涨，跟风股5-7%
- 推荐时刚好在板块情绪最高点，5分钟后开始回落

**检测条件：**
```python
if 当日主题切换 >= 2次 and 大盘指数偏弱:
    # 标记为"轮动过快日"
    # 只选涨幅1-3%的标的
    # 如果找不到 → 明确说"不适合建仓"
```

## 修正后的选股流程

在Step 3（板块内选股）中增加一道过滤：

```python
# 原流程：板块确认 → 找涨幅最大非涨停股 → 推荐
# 新流程：板块确认 → 先看1-4%区间 → 找蜡烛最干净的 → 推荐
# 
# 涨幅1-4%优先于涨幅5-7%，即使后者看起来"更强"
# 因为5-7%的更强往往是"更接近日内高点"
```
