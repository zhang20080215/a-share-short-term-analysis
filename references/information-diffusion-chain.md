# 信息扩散链：冷门票如何被发现的

## 核心概念

一只股票上涨的催化剂，通常在涨之前1-3个月就已经存在了。
**你什么时候看到它，取决于这条信息扩散链铺到了哪个环节。**

## 四阶段模型

| 发现顺序 | 参与者 | 信息源 | 利润空间 | 持仓行为 |
|:-------:|:------|:------|:--------:|:--------|
| 🥇 **第1批** | 产业研究员、产业链内部人 | 盯价格表、跑工厂、行业协会 | **100%+** | 慢慢建仓，不声张 |
| 🥈 **第2批** | 机构投资者（公募/私募/QFII） | 看研报、听电话会、产业调研 | 50-100% | 分批买入，推动价格 |
| 🥉 **第3批** | 游资/VIP订阅者 | 财联社VIP/雪球/涨停板敢死队 | 20-50% | 加速拉升，放量 |
| 🏁 **第4批** | 散户/普通交易者 | 涨幅榜/龙虎榜/新闻/朋友推荐 | **接盘阶段** | 追高买入 |

## 实战案例：红星发展 600367（碳酸锶涨价 2026-06）

### 第1批：产业研究员
**2025年1月** — 化工行业研究员发现碳酸锶供给收紧：头部厂商停产 + 落后产能淘汰令到期 → 供需缺口。红星和金瑞矿业是A股唯二标的。
→ 写进报告，内部推给机构客户。

### 第2批：机构投资者
**2025年1-4月** — 机构研报消化后，开始建仓。股价从19元缓慢爬升，日均成交1-2亿，不显眼。
→ 这个阶段持续了几个月，股价完成了大部分涨幅基础。

### 第3批：游资/VIP
**2026年1月16日** — 财联社风口研报发布"化工品种涨价势头凶猛"（明确写红星发展+金瑞矿业）。
→ VIP订阅用户看到，游资开始关注。股价从27加速。

### 第4批：散户/你
**2026年6月3日** — 红星发展涨停，上了涨幅榜，你打开券商APP看到了它。
→ 股价已从19涨到43（+126%），7天加速从27到43（+59%）

### 关键教训
- **你看到它的时候，第1-2批已经在里面了。** 涨停是信息扩散到最终端的信号，不是起点。
- **倒推法**：看到涨停 → 查起涨点 → 查当时催化 → 判断自己在信息链的哪一环
- **信息链位置决定策略**：第1批可以长持，第2批可以中线，第3批做短线，第4批只能做超短线或放弃

## 时点判断法

当用户问"为什么XX涨"或"为什么有人注意到XX"时，用K线时间倒推：

```python
# 1. 拉60日K线
# 2. 找到三个时点：
低点日期 = K线最低点（信息进入链条的时间）
突破日期 = 首次放量突破（第2批开始买入的时间）  
加速日期 = 放量大涨+连续阳线（第3批入场的时间）
# 3. 比较当前日期与三个时点的距离
# 4. 判断用户当前处在信息链的什么位置
```

**结论：** 如果K线已连续涨5天+放巨量+涨幅榜前列 → 基本已经在第4批（末端），追涨需极度谨慎。

## 启发

这个框架也回答了另一个关键问题：
- 为什么研究员/产业人士比机构赚得多？因为他们信息优势最大
- 为什么机构比散户赚得多？因为他们信息链条位置更靠前
- 为什么散户总在高位接盘？因为看到信息的时候已经是最后一环

**交易者的任务不是"发现牛股"，而是"判断自己处在信息链的哪个位置"。**
