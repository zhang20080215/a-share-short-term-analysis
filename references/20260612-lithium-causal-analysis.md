## 双层归因

### Layer 1: 大主题——有色金属/资源全线爆发

**驱动：全球商品涨价周期**
- 铜+7.5%、铅锌+9.6%、镍+7.3%、黄金+5.8%同步上涨
- ECB鹰派表态（13:00电报："如有必要7月再次加息"）→ 欧元走强 → 美元走弱 → 以美元计价的大宗商品上涨
- 中国基建/制造业需求复苏预期

### Layer 2: 子板块——锂矿自身催化

**来源：财联社 13:05 电报**

> "受6月多地推出汽车购置补贴与新能源置换政策推动，国内新能源车终端需求环比回升，动力电池厂商排产上调，上游锂盐采购量小幅增长。储能赛道保持稳定增量，AI算力配套储能及大型风光储能项目持续落地，储能电池锂消耗稳步提升，有效对冲乘用车需求波动。"

**三条催化链：**

1. **🔵 政策补贴→需求回暖：** 6月多地汽车购置补贴+新能源置换政策 → 新能源车终端需求环比回升 → 电池厂排产上调 → 上游锂盐采购量增长
2. **🟢 储能增量对冲：** AI算力配套储能 + 大型风光储能项目持续落地 → 储能电池锂消耗稳步提升 → 有效对冲乘用车需求波动（这条是关键——解释了为什么锂矿不跟随乘用车增速放缓而下跌）
3. **🟡 超跌反弹：** 从6/1到6/8连跌7%，60日分位降至42%（中低位），天齐从82.49高点回撤24%

## 锂矿跑输铜/金的原因

| 维度 | 基本金属（铜/铝） | 锂矿 |
|:---:|:-----------------:|:----:|
| 涨幅 | +7.5% / +4.8% | +3.71% |
| 驱动性质 | **全球商品周期**（强） | **国内政策补贴**（偏弱） |
| 资金偏好 | 周期股、期货联动 | 成长股、估值敏感 |
| 当前位置 | 60日26%分位 | 60日42%分位（相对不便宜） |

**核心原因：** 今日炒的是"全球商品涨价"（铜/铝/镍是直接受益方），锂矿的补贴政策是内需逻辑，与全球商品联动性弱。锂矿能涨是因为整个资源大主题情绪外溢，并非因为它的催化最强。

**差异化判断（由成交额确认）：** 天齐锂业成交43亿 🔥，赣锋成交41亿，量能放大明显。说明有资金在锂矿建仓而非单纯跟风。涨幅温和（+2.59%）是因为锂矿不是今天的主角，但资金流入是实打实的——所以判断为"还没轮到，补涨空间大"，而非"弹性差，不值得买"。

## 经验教训

1. **子板块在大主题中跑输是常态**——不意味着该子板块逻辑差，可能只是资金偏好不同
2. **用成交额区分"弱"和"没拉"**：天齐43亿成交但只涨2.59% = 有资金建仓但还没发力。如果成交清淡且涨幅小 = 逻辑不被认可
3. **双层归因的实操价值**：告诉用户"大主题是宏观驱动，子板块有自身催化，两者叠加"，比只说一个层面更完整
4. CLS电报是归因的核心来源，下午13:05的锂电池专题快讯直接给出了三条催化链
