# 对冲与防守工具箱（防守不止"空仓"一种）

> **2026-08-06 新增。** 框架 risk-off 时只会"全撤成现金"。**"保守的激进主义者"的保守，
> 应该体现在有定义的下行保护，而不是只会割成现金。** 满仓遇到系统性风险，除了割就是扛——这不够。
> 本文件是**方法论**，不涉及实际下单（下单是用户自己的动作，且开通需门槛）。
> 相关：SKILL.md「外部突发事件检测与攻防切换」、[[资金管理体系]]（回撤熔断）。

---

## 0. 什么时候需要对冲（而不是直接清仓）

| 场景 | 首选 | 理由 |
|:---|:---|:---|
| 底仓/长线仓不想卖(税/成本/看好中线)但怕短期系统性下跌 | **对冲** | 保留底仓，只对冲市场beta |
| 满仓过夜 + 大盘明显走弱 + 隔夜外盘风险 | 对冲/减仓 | 锁隔夜风险 |
| 外部冲击(熔断/地缘)但持仓有独立alpha | 对冲市场、保留alpha | 见 SKILL.md 攻防切换 |
| 纯短线仓、无留恋 | **直接止损/清仓** | 短线仓不值得对冲成本 |

> **原则：底仓用对冲保护，短线仓用止损了结。** 对冲是为"卖不得/不想卖"的仓位准备的。

## 1. 工具箱（适用场景 + 门槛 + 成本）

| 工具 | 做什么 | 适用 | 门槛/成本/风险 |
|:---|:---|:---|:---|
| **股指期货 IF/IH/IC/IM** | 做空对应指数(沪深300/上证50/中证500/1000)对冲市场beta | 持仓贴近某宽基风格时最有效 | 需开通(50万+考试)，保证金~12%，注意**贴水**(空头反而占便宜或吃亏)、每点乘数大 |
| **300ETF/500ETF 期权 put** | 买入认沽=给持仓买保险，损失封顶在权利金 | 想要**下跌保护但保留上涨**时最优 | 需开通期权，付**权利金**(时间价值会衰减)，适合事件前短期保护 |
| **融券卖出** | 融券做空个股/ETF对冲 | 想对冲**具体个股**风险 | 需两融账户，**券源常缺**、融券费率高(年化8-10%+)，T+1 |
| **反向/跨境ETF** | 用现货ETF做粗对冲(如某些行业反向敞口) | 无衍生品权限时的粗替代 | 精度低，跟踪误差，只能粗对冲方向 |

## 2. 对冲比例怎么估（beta 中性化）

不是有多少持仓就对冲多少市值，要按**组合对市场的beta**折算：
```
需对冲名义市值 = 持仓总市值 × 组合beta × 对冲比例k

  组合beta：高beta成长仓≈1.2-1.5，防御仓(公用/银行)≈0.6-0.8
  对冲比例k：
    - 部分对冲(削峰) k=0.3-0.5   → 降波动，仍保留部分方向
    - 大部对冲(避险) k=0.7-1.0   → 接近市场中性，只留alpha

指数期货手数 ≈ 需对冲名义市值 / (指数点位 × 合约乘数)
```
> **保守的激进主义者的用法：** 平时不对冲(留进攻性)；出现外部冲击/账户回撤触发时，用 k=0.5 快速削掉一半市场波动，保留个股alpha和翻身机会，而不是一刀清仓踏空反弹。

## 3. 与框架的整合（触发点）

**接 SKILL.md「外部突发事件检测与攻防切换」+ [[资金管理体系]]「回撤熔断」：**
```
外部冲击(熔断/地缘) 或 账户回撤触发:
  ├─ 短线仓 → 止损了结(原逻辑)
  ├─ 底仓/长线仓 →
  │    有衍生品权限 → 股指期货/期权put 部分对冲(k=0.5)，保留底仓
  │    无权限       → 减仓 或 反向ETF粗对冲
  └─ 冲击缓解后(见"恐慌缓解后扫描") → 逐步撤对冲，恢复进攻
```

## 4. 常见陷阱

| 陷阱 | 纠正 |
|:---|:---|
| ❌ 对冲短线小仓 | 短线仓直接止损，对冲成本不划算 |
| ❌ 无视期货贴水 | IC/IM 常年贴水，做空要考虑贴水损益，不是纯保险 |
| ❌ 买put长期持有 | 时间价值衰减，put是**事件前短期**保护，不是长期持有 |
| ❌ 满仓才想起对冲 | 对冲是预案，风险来临前就该定好k和工具，不是临时抱佛脚 |
| ❌ 把对冲当赚钱工具 | 对冲目的是**降波动/保住底仓**，不是靠做空获利，别喧宾夺主 |

> ⚠️ 本文件为方法论。实际开通两融/期货/期权及下单由用户自行决定，涉及门槛与适当性要求。
