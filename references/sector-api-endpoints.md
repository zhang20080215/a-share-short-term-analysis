# A股板块数据API参考

## 东方财富板块排行（推荐）

获取今日所有行业板块涨幅排名：

```bash
curl -s "https://push2.eastmoney.com/api/qt/clist/get?cb=j&pn=1&pz=20&po=1&np=1&fields=f2,f3,f4,f8,f12,f14,f104,f105&fid=f3&fs=m:90+t:2"
```

**响应字段：**
| 字段 | 含义 | 示例 |
|:---:|:---|:---:|
| f2 | 最新价 | 4542.97 |
| f3 | 涨幅% (×100) | 1177 → 11.77% |
| f4 | 涨跌额 | 478.33 |
| f8 | 量比 | 3.5 |
| f12 | 板块代码 | BK1329 |
| f14 | 板块名称 | 集成电路制造 |
| f104 | 板块内股票总数 | 8 |
| f105 | 涨停家数 | 0 |

**字段f3是百分比×100**，例如1177=11.77%。使用Python解析时除以100。

**参数说明：**
- `fs=m:90+t:2` — 行业板块榜单
- `po=1` — 降序排列（涨幅从高到低）
- `pz=20` — 每页20条

**JSONP 回调处理：**
该API在 `cb=` 为空时有时返回空响应。设置 `cb=j` 后响应包裹在 `j(...)` JSONP回调中，需去掉外层再解析：

```python
import re, json
raw = result.stdout.decode('utf-8', errors='replace')
m = re.search(r'j\\((.+)\\)$', raw)
if m:
    data = json.loads(m.group(1))
else:
    # 也可能没有JSONP包裹，尝试直接解析
    data = json.loads(raw)
# 或更稳健的：提取第一个{到最后一个}
start = raw.find('{')
end = raw.rfind('}')
data = json.loads(raw[start:end+1])
```

推荐使用 `cb=j` 形式（最稳定），然后按第二种稳健方式提取JSON体。

### ⚠️ 铁律：绝不对BK代码做假设性查询（2026-06-15 新增）

**永远不要从记忆或经验中猜测一个板块的BK代码。** 直接使用 `fs=b:BKxxxx` 查询成分股时，如果BK代码错误，API会**静默返回其他板块的数据**（没有错误提示），导致你分析的是完全错误的股票。

**真实教训（2026-06-15 全局选股）：**
| 猜测的BK | 意图板块 | 实际返回的数据 | 偏差 |
|:--------:|:--------:|:--------------:|:----:|
| BK0901 | 印制电路板(PCB) | 光学光电子（立讯精密、水晶光电、欧菲光） | ❌ 完全不同 |
| BK0880 | 被动元件 | 混合电子股（京东方、信维通信、机器人） | ❌ 数据混乱 |
| BK0732 | 通信网络设备 | 贵金属/黄金（招金黄金、赤峰黄金） | ❌ 完全不同 |

**正确的三步工作流：**

```
Step 1: 查询板块排行时**必须包含f12字段**
  curl "...&fields=f2,f3,f4,f8,f12,f14,f104,f105&fid=f3&fs=m:90+t:2"
  #                        ^^^^ f12 = BK代码

Step 2: 从板块排行结果中提取目标板块的f12(即BK代码)
  for item in items:
      if item['f14'] == '印制电路板':
          bk_code = item['f12']  # 这才是正确的BK代码

Step 3: 用提取到的BK代码查询成分股
  curl "...fs=b:{bk_code}"
```

**永远不要在代码里硬编码BK代码。** 先跑板块排行 → 提取f12 → 再查成分股。多一次API调用，少一次数据灾难。

## 板块内个股查询

获取某板块内的成分股排名（按涨幅降序）：

```bash
curl -s "https://push2.eastmoney.com/api/qt/clist/get?cb=&pn=1&pz=10&po=1&np=1&fields=f2,f3,f8,f12,f14&fid=f3&fs=m:90+t:2+f:!50"
```

替换 `fs` 参数中的板块代码：
- `fs=m:90+t:2` = 行业板块榜单
- `fs=b:BK1036` = 半导体板块成分股

**注意：** `fs=b:板块代码` 格式有时返回空数据。备选方案：使用个股代码手动查询，或使用 `fs=m:90+t:3` 查询概念板块。

### ⚠️ `fs=b:BKxxx` 成分股API可靠性问题（经验证）

该端点**经常返回空数据**（`{"rc":0,"data":{"diff":null}}`），尤其是在盘中和非交易时段。在2026-05-26会话中连续对所有板块查询均返回空。

**验证有效的工作流：直接查询已知候选股**

当`fs=b:BKxxx`失败时，直接用Tencent API查询板块内核心股：

1. **先查该板块涨幅榜领涨股**
   - 记住资源板块核心代码（如黄金=山东黄金/紫金/中金，铝=中国铝业/云铝，钨=厦门钨业等）
   - 或从板块名称推断核心股

2. **直接批量查询**
```bash
curl -s --max-time 10 "https://qt.gtimg.cn/q=sh600547,sh600489,sh601899" | iconv -f GBK -t UTF-8
```

3. **如需发现板块内还有哪些股**，使用东方财富个股主页搜索，或记住A股各板块的常见龙头股名单（作为领域知识储备）。

## 批量个股实时行情

一次查询多只股票（Tencent API）：

```bash
curl -sL --max-time 10 "https://qt.gtimg.cn/q=sh600089,sh603799,sz159636,sz300274,sh600584,sh688981,sz002371" | iconv -f GBK -t UTF-8
```

返回格式：`v_市场代码="数据~以~波浪线~分隔"`

**关键字段索引（从0开始，~分隔）：**
| 索引 | 含义 |
|:---:|:---:|
| 1 | 名称 |
| 2 | 代码 |
| 3 | 现价 |
| 4 | 昨收 |
| 5 | 今开 |
| 6 | 成交量（手） |
| 30 | 时间戳 |
| 31 | 涨跌额 |
| 32 | 涨跌幅% |
| 33 | 最高 |
| 34 | 最低 |
| 37 | 成交额（万元） |
| 38 | 换手率% |

**解析示例（Python）：**
```python
import subprocess, re
result = subprocess.run(["curl", "-s", "--max-time", "10", "https://qt.gtimg.cn/q=sh600089"],
    capture_output=True, timeout=10)
data = result.stdout.decode('gbk', errors='replace')
m = re.search(r'"([^"]+)"', data)
fields = m.group(1).split('~')
price = float(fields[3])     # 现价
change_pct = float(fields[32])  # 涨跌幅%
volume = float(fields[6])    # 成交量
```

**前端（沪/深）前缀：**
- 沪市A股: `sh`（如 `sh600089`）
- 深市主板/创业板: `sz`（如 `sz300274`）
- 科创板: `sh`（如 `sh688981`）
