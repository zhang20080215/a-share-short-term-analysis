# ST/\*ST 股票政策分析框架

> **适用范围：** 用户**主动问**某只ST/\*ST股票的基本面/风险/政策影响时使用。
> **不适用范围：** 全市场扫描中自动推荐ST/\*ST股票（已被SKILL.md的排除规则禁止）。

## 一、ST vs \*ST 含义区分

| 标识 | 含义 | 涨跌幅 | 风险等级 |
|:----|:-----|:-----:|:-------:|
| **ST** | 其他风险警示（Special Treatment） | ±5% | ⚠️ 中等 |
| **\*ST** | 退市风险警示（Delisting Risk Warning） | ±5% | 🔴 高 |

**条件触发区别：**
- **ST触发：** 公司经营异常、违规担保、关联方资金占用、主要银行账户冻结、董事会无法召开等
- **\*ST触发：** 最近一个会计年度净利润为负且营收<3亿、净资产为负、审计意见无法表示/否定、追溯重述后净资产为负等

## 二、退市/摘帽核心规则（2024修订版，2025年起实施）

### 财务类退市条件（\*ST后转退市）

| 条件 | 说明 |
|:---|:-----|
| 净利润为负 + 营收<3亿 | 连续两年触发 → 终止上市 |
| 净资产为负 | 连续两年触发 → 终止上市 |
| 审计意见无法表示/否定 | 连续两年 → 终止上市 |

### 交易类退市条件（无须经历\*ST，直接退市）

| 条件 | 说明 |
|:---|:-----|
| 连续20日收盘价 < 1元 | 面值退市 |
| 连续20日市值 < 3亿 | 市值退市 |
| 连续20日股东人数 < 2000人 | 流动性退市 |

### 摘帽条件（\*ST→恢复正常）

- 最近一个会计年度净利润转正（扣非净利润为正更佳）
- 营收≥3亿（如果净利润为正但营收<3亿仍不能摘帽）
- 净资产为正
- 审计意见为标准无保留
- 满足全部条件后向交易所申请，审核通过后摘帽

## 三、ST/\*ST股票的涨跌幅规则

### 当前规则（截至2026年7月）

| 股票类型 | 涨跌幅限制 |
|:--------|:---------:|
| 正常A股 | ±10% |
| ST/\*ST股票 | **±5%** |
| 科创/创业板ST/\*ST | ±20%（同板块规则） |

### 用户提及的政策变化（2026年7月）

> 如用户所说属实：下周起**ST/\*ST股票涨跌幅统一改为±10%**（与正常A股一致）

#### 政策变化的影响分析框架

| 维度 | 5%制（当前） | 10%制（新政） | 对\*ST股的影响 |
|:----|:----------:|:-----------:|:-------------|
| **流动性** | 低，游资进出难 | **高**，吸引更多资金 | 🟢 利好 |
| **跌停亏损速度** | 一天最多亏5% | 一天最多亏10% | 🔴 风险翻倍 |
| **涨停爆发力** | 连续涨停慢（5%→5%→5%） | 快速爆发（10%→10%→10%） | 🟢 利好博弈型标的 |
| **摘帽博弈效率** | 慢，空间有限 | 快，10%涨跌幅更高效 | 🟢 利好有摘帽希望的\*ST |
| **散户承受力** | 无差别 | 心理冲击大 | 🔴 利空无研究的散户 |

**综合判断：**
- 对**有摘帽希望**的\*ST股（资产优质、亏损可控）：短期利好，效率提升
- 对**将退市**的\*ST股（亏损不可逆、资不抵债）：利空，跌停更快更痛
- 对\*ST板块整体：短期情绪刺激，不改基本面，退市条件不变

## 四、\*ST股的分析要点

当用户问具体某只\*ST股票时，按以下维度分析：

### 1. 退市风险量化

| 维度 | 数据来源 | 说明 |
|:----|:--------|:-----|
| 净资产 | 年报/季报 | 是否为负？如为负→退市风险极高 |
| 净利润 | 年报/季报 | 亏损还是盈利？2026年能否转正？ |
| 营收规模 | 年报 | 是否>3亿？ |
| 审计意见 | 年报 | 是否标准无保留？ |
| 股价 | 实时行情 | 是否接近1元面值？ **面值退市最快，无须等年报** |

### 2. 摘帽可行性判断

```
摘帽希望高 ← 特征
  ├─ 股价远高于1元（无面值退风险）
  ├─ 市值>50亿（无市值退风险）
  ├─ 净资产为正且较为充裕（>30亿）
  ├─ 亏损有明确原因（如一次性减值），不是经营恶化
  ├─ 有资产处置/重组/引入战投等自救计划
  └─ PB<1（破净=市场极度悲观，如有转机修复空间大）
  
摘帽希望低 ← 特征
  ├─ 股价在1-2元附近（面值退风险高悬）
  ├─ 净资产为负
  ├─ 连续多年主业亏损，无明显转机
  ├─ 审计持续非标
  └─ 无自救动作或自救无效
```

### 3. PB 破净的解释

**对于\*ST闻泰这类PB=0.35（市净率0.35倍）：**
- 含义：市场价仅公司净资产的35%，极度低估
- 可能原因：①市场认为资产质量差（减值风险）②delisting risk溢价 ③行业悲观预期已price in
- 破净≠安全：如果净资产本身是虚的（商誉高、坏账多），破净也没用
- 破净+有希望摘帽=可能的α机会（PB从0.35修复到1.0 = 186%空间）

### 4. 交易层面风险

| 风险 | 说明 |
|:----|:-----|
| 流动性风险 | \*ST股日成交额通常远低于正常股，大资金进出难 |
| 涨停板拥堵 | 5%限制下，利好发生时连续涨停买不进去 |
| 跌停板出不去 | 利空发生时连续跌停卖不出来 |
| 机构清仓 | 很多机构的投资规则禁止持仓ST股，触发被动清仓 |
| 两融标的剔除 | \*ST后通常被调出融资融券标的，杠杆盘被迫平仓 |
