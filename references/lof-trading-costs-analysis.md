# LOF/ETF 做T成本与收益分析

## 何时使用
当用户问在场内LOF/ETF上做T（T+0或T+1日内回转交易）是否划算、多少差价才有意义时。适用于跨境的T+0 QDII基金或普通T+1基金的隔夜做T。

## 做T收益模型

### 摩擦成本计算框架

```
总摩擦成本 = 佣金费率×2 + 买卖价差% + 滑点冲击%
```

### 典型参数（A股市场标准）

| 成本项 | 费率 | 说明 |
|:------|:----:|:------|
| 佣金（每边） | 万2.5（0.025%） | 部分券商有最低5元限制，小金额时影响大 |
| 佣金来回合计 | **0.05%** | 买+卖各一次 |
| 买卖价差 | 0.1~0.3% | 取决于流动性。LOF通常比ETF宽 |
| 滑点/冲击成本 | 0.1~0.3% | 取决于单量和盘口深度 |
| **合计摩擦** | **0.3~0.6%** | 实际可操作范围 |

### 换算为"几分"（以2.35元LOF为例）

| 价差 | 涨幅% | 扣除成本后净赚 | 判断 |
|:---:|:-----:|:-------------:|:----:|
| **1分** | 0.43% | ≈盈亏平衡 | 白忙活，不值得 |
| **2分** | 0.86% | 净赚≈0.4% | 有点意义 |
| **3分** | 1.28% | 净赚≈0.8% | 不错的T |

### 结论公式

```
做T最低阈值 = 当前价格 × (总摩擦成本 / 100)
当目标涨幅% > 总摩擦成本% + 0.3%时，做T才有意义
```

## LOF特有风险：溢价干扰

T+0做T在LOF上的核心问题不是成本，而是**溢价变动**：

```
做T盈亏 ≠ 价格涨跌
做T盈亏 = 价格涨跌 + 溢价变化
```

**案例：** 如果溢价从14.7%缩到12%，即使价格不动，你亏了2.7%。溢价变化可以轻易吃掉日内微薄的成本利润。

**规则：**
- 高溢价LOF（>8%）：做T本质是赌溢价，不是赌净值。不做为妙
- 溢价5%以内：溢价变化影响有限，可做正常技术T
- 溢价在1-2%正常范围：按普通个股做T思路

## 实操示例

```python
price = 2.35  # 当前价
commission_rate = 0.00025  # 万2.5
bid_ask_spread = 0.003  # 买卖一档差（约0.13%）
slippage = 0.002  # 滑点估算

total_cost_pct = (commission_rate * 2 + bid_ask_spread/price + slippage) * 100
min_target_pct = total_cost_pct + 0.3
min_target_cents = int(price * min_target_pct / 100 / 0.01) * 0.01

print(f"最低有意义涨幅: {min_target_pct:.1f}% → 约{min_target_cents:.2f}元")
```
