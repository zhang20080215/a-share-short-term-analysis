# 止盈体系（何时走、怎么让利润奔跑）

> **2026-08-06 新增。** 框架此前只有一句"让利润奔跑、用跟踪止盈",没有任何可执行规则——这是一句正确的废话。
> **对何时买有20条规则,对何时卖近乎0条。没有出场纪律,"让利润奔跑"最后往往变成"把浮盈坐回去"。**
> 相关：[[资金管理体系]]（仓位与止损）、SKILL.md「长线底仓的波段管理」（底仓走高抛低吸，不走本文的跟踪止盈）。

---

## 0. 先分清：交易仓 vs 底仓，走不同的出场逻辑

| 仓位性质 | 出场逻辑 | 依据 |
|:---|:---|:---|
| **交易仓**（短线/波段建仓） | **分批止盈 + 跟踪止盈**（本文件） | 让利润奔跑,趋势破了才走 |
| **长线底仓**（核心持有） | **高抛低吸波段** | SKILL.md「长线底仓的波段管理」 |

**不要把两者混用**：底仓在区间高抛低吸,交易仓靠跟踪止盈吃趋势。本文件只管**交易仓**。

---

## 1. 分批止盈（锁定 + 奔跑，二者兼得）

不设"硬止盈价"一次性清仓,而是分批：

```
第一批（锁利）：达到盈亏比 1:2 时（盈利 = 2×初始止损距离），减 1/3
   → 此时把剩余仓位的止损上移到成本价（保本），这笔交易已"立于不败"
第二批（奔跑）：剩余 2/3 用跟踪止盈持有，让趋势票继续跑
```

**盈亏比锚点**：初始止损距离若为 5%,则第一目标 = +10%(减1/3),之后跟踪。

---

## 2. 分级跟踪止盈（剩余仓位怎么走）

剩余仓位用**趋势破位**信号出,而不是固定涨幅。按强弱分级：

| 触发信号 | 动作 | 适用 |
|:---|:---|:---|
| **跌破 MA5** | 走 1/2 | 短线加速票,MA5是生命线 |
| **跌破 MA10** | 清剩余 | 短线趋势确认走坏 |
| **从最高点回撤 ≥ 8%（或 1.5×ATR）** | 清仓 | 波动率自适应,替代固定回撤 |
| **放巨量长上影（上影>40% + 量>1.5倍）** | 止盈 1/2 | 冲高派发信号,先减半锁利 |
| **单日大阴破位（跌>5%跌破关键支撑）** | 清仓 | 趋势破坏,不恋战 |

**取最先触发的信号执行。** 强势主升浪可只用MA10/回撤法给趋势更大呼吸空间;弱势/高位票用MA5法收紧。

---

## 3. 移动止损（保本后的跟踪，与止盈一体）

分批止盈后,剩余仓位的止损**只上移不下移**：
```
建仓后         止损 = 入场 - 2×ATR（见资金管理体系）
第一目标达成后 止损 = 成本价（保本）
每创新高       止损 = max(旧止损, 最新MA5 或 最高点-1.5×ATR)
```
- 移动止损让"让利润奔跑"变成可执行的机械动作,而不是靠盘感。
- 触及移动止损即出,不找理由再等——呼应"止损已破后的第一次反弹是最后出局窗口"教训。

---

## 4. 什么时候该"硬止盈"（例外）

默认不设硬止盈,但以下情况例外,直接清仓不跟踪：
- **板块高潮日**(涨停≥5只/涨跌比>5:1)且自己已+7%以上 → 兑现,不赌次日
- **利好兑现式冲高**(如业绩/中标当日高开大涨后走弱)→ 见光死,先走
- **触及重大前高/历史套牢密集区 + 放量滞涨** → 减仓过墙难

---

## 5. 输出格式（给出建仓建议时同时给出场计划）

推荐建仓时,止盈计划必须一并给出,不能只给买入：
```
**出场计划：**
- 初始止损：¥XX（-X%，= X×ATR 或支撑下方）
- 第一目标：¥XX（盈亏比1:2）→ 减1/3，剩余止损上移保本
- 跟踪止盈：剩余仓位跌破MA5走半 / 回撤8%(或1.5ATR)清仓
- 移动止损：每创新高上移到 max(MA5, 最高-1.5ATR)
```
