# 端午节休市检测实战案例（2026-06-19）

## 场景
14:00 cron job 运行全局扫描选股，但当日为端午节，A股休市。

## 检测过程

### Step 1: 发现数据异常
```bash
curl -s "https://qt.gtimg.cn/q=sh000001" | iconv -f GBK -t UTF-8
```
- 上证指数回复中时间戳为 `20260618161419`（昨天16:14）
- 深证、创业板、科创50同理，全部是前一天收盘数据
- 个股行情（长电科技等）同样返回前一天时间戳

### Step 2: 排除push2封锁假象
- CLS电报14:00前后有实时新闻更新（显示"2026.06.19 星期五 14:11:49"）
- 但所有新闻都是国际内容：WTI原油+1%、日本国债收益率、欧股期货、英国零售、德国PPI
- **没有任何A股午评、盘中快讯、板块涨跌信息**
- 这说明网站本身在运行，但A股交易数据不存在

### Step 3: 确认节假日关键词
搜索CLS页面内容发现：
```
13:19:20【2026端午档首日电影票房破亿 上映数量创近十年同期新高】
```
- "端午档首日"明确指端午节第一天
- 当天周五，与端午节日期吻合

### Step 4: 确认非交易日
- API返回昨日时间戳 ✅
- CLS无A股交易内容 ✅
- 端午关键词确认 ✅
→ **结论：6/19（周五）端午节，A股休市，下周一（6/22）恢复交易**

## 切换明日前瞻输出
- 使用昨日（6/18）收盘数据做分析
- 从CLS提取关键国际消息（原油、美股期货下跌、中东局势）
- 输出明日前瞻格式

## 与push2封锁的区别

| 信号 | push2封锁（正常交易日） | 节假日休市 |
|:----|:---------------------:|:---------:|
| qt.gtimg.cn时间戳 | 今日实时 | 前一天 |
| CLS电报内容 | 有A股午评/板块排名/涨停数据 | 仅国际新闻 |
| push2返回值 | 空（被IP限流） | 不适用（没有今日数据） |
| CLS板块widget | 显示今日板块排行 | 显示昨日板块排行（与指数匹配） |
