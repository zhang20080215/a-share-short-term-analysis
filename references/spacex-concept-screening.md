# 案例：SpaceX IPO概念股筛选（2026-06-01）

## 场景

用户连续发送股票代码，逐个分析后最终揭示共同主题：**SpaceX 6月12日上市**概念。这是典型的"渐进式揭示"模式——用户知道主题但让你自己从代码中发现。

## 用户行为模式

用户发送代码的方式：
```
301005 → 688102 → 603308 → 600895 → 600783 → 002202
"叠加6月12日Spacx上市呢"
```

**识别信号：** 当用户连续发送不同板块的代码、且代码涉及某一共同主题（航天/军工/新材料）时，尝试找共同线索。不要等用户明说再回头重分析。

## SpaceX概念股业务关联度分级

基于主营业务描述（来源：东方财富datacenter API `RPT_F10_ORG_BASICINFO`字段`MAIN_BUSINESS`）：

| 等级 | 股票 | 主营业务关键词 | SpaceX关联 |
|:---:|:----|:-------------|:----------|
| ⭐⭐⭐ **最直接** | 斯瑞新材 688102 | **液体火箭发动机推力室内壁**、高强高导铜合金 | 火箭发动机燃烧室/喷管核心材料。SpaceX的Merlin/Raptor发动机均使用铜合金内壁 |
| ⭐⭐ **相关** | 超捷股份 301005 | 高强度精密紧固件、异形连接件 | 航空航天领域通用精密件，可用于火箭结构 |
| ⭐ **泛航天** | 神剑股份 002361 | 化工新材料、高端装备制造 | 概念相关但非直接供应商 |
| ❌ **无关** | 应流股份 603308 | 石油天然气/矿山设备零部件 | 主营与航天无直接关联 |

### 查询方法

```python
# 查主营业务API
curl "https://datacenter.eastmoney.com/securities/api/data/v1/get?\
reportName=RPT_F10_ORG_BASICINFO&columns=SECURITY_CODE,MAIN_BUSINESS&\
filter=(SECURITY_CODE=%22${code}%22)&pageNumber=1&pageSize=1&client=PC&v=0827"
```

**注意：** 此API偶尔不通，可改用浏览器访问同花顺/东方财富个股F10页面。

## 结合盘面的分析框架

当用户把"远期事件"（如SpaceX上市）与"今日行情"叠加时，分析框架：

```
问题 = "今天能买什么为X事件做准备？"

Step 1: 筛选直接关联标的（按业务关联度排序）
Step 2: 过滤不可买的（已涨停、大涨>7%追高风险）
Step 3: 检查各标的技术位置（超跌/横盘/已涨）
Step 4: 找到"关联度高 + 位置低 + 还没涨"的最佳买点

最佳状态 = 概念纯正 + 超跌/横盘 + 今天还没启动
```

### 实战判断（2026-06-01）

| 标的 | 关联度 | 今日涨幅 | 近期趋势 | 判断 |
|:----|:-----:|:-------:|:--------|:----|
| 斯瑞新材 688102 | ⭐⭐⭐ | **+0.40%** | 48→35跌27%在34.6止跌 | ✅ **最佳——纯正+低位+未动** |
| 超捷股份 301005 | ⭐⭐ | **-1.59%** | 205→140跌32%还在创新低 | ❌ 下跌未止，接飞刀 |
| 神剑股份 002361 | ⭐ | **-0.20%** | 22→15跌32%缩量阴跌 | ❌ 没人接盘 |
| 应流股份 603308 | ❌ | **+0.14%** | 72→64跌11% | 概念不相关 |

**结论：** 斯瑞新材是这批里唯一兼具"纯正概念+低位+未启动"三个条件的标的。

## 学习要点

1. **渐进式揭示模式识别：** 用户发多个代码时，先找共性再逐股分析，而非孤立分析每个
2. **关联度分级：** 查主营API确定概念纯度，不要仅凭名称或印象判断
3. **时间窗口：** SpaceX 6/12上市，距当前（6/1）有11天预热窗口。有明确时间节点的主题比模糊概念更可操作
4. **盘面叠加：** 远期事件再好，也要结合今天盘面的资金态度——斯瑞今天只有+0.40%缩量反弹，说明资金还没来（正好是埋伏机会）
