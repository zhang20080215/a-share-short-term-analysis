# 2026-07-01: "不用强制换方向" — 多轮全局选股的核心修正

## 现象
会话中用户连续3次要求全局选股：
1. 推荐三花智控（机器人方向）→ 用户未买
2. **错误：** 强行换到东阳光（被动元件/国巨涨价方向）→ 用户说"太高了"
3. **错误：** 强行换到第一创业（证券方向）→ 被用户纠正

用户纠正："不用强制换方向，在选股框架下面推荐最合理的方向即可"

## 根因
选股框架中的"用户反复要求全局选股的处理"表规定了"第二次→换方向推荐"，这造成了机械执行：
- 第二次全局选股时，自动认为"用户不感兴趣→必须换方向"
- 但实际上用户只是还没决定买，不是否定那个方向
- 数据层面，机器人方向（三花智控）在当天仍然是最优选择（60日25%分位+板块3只涨停+国巨涨价催化被动元件联动）

## 修正
### 1. 行为修正
- 第二次全局选股 ≠ 必须换方向
- 正确做法：**重新跑完整六步法**，让最新数据决定方向
- 数据引擎优先于计数器逻辑

### 2. 决策树

```
第二次全局选股请求
├─ 刷新板块排行、大盘、候选股数据
├─ 判断原方向在当前数据下是否仍是最优
│  ├─ 是 → 同主题内调整（换细分/换龙头/换价位）
│  └─ 否 → 数据驱动的方向切换
└─ 输出推荐时不提"这是换方向"，只说"基于当前数据的最佳选择"
```

### 3. 关键信号
- 方向由当前时段（同一日）的板块排行数据决定
- 用户没买 ≠ 方向错误（可能只是时机/价位/仓位不合适）
- 只有在原方向的板块强度明显衰退、或新方向有本质性更强的催化时才切换
