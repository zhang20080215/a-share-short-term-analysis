# 提前量扫描：看明天，不是今天

## 核心原则

全局选股时，第一遍扫描看到的是"今天什么在涨"。但真正有价值的是第二遍——**今天什么在蓄力、明天什么可能启动**。

用户原话："关键不是看今天，而是打出提前量，看明天和后续。"

## 三类"明天启动"形态

### 1. 大阳次日缩量蓄力 ⭐⭐⭐

**识别：** 昨天+4%以上放量阳线 → 今天±1%以内缩量横盘

```
例：三七互娱 07/15 +4.8% 量59万 → 07/16 -0.6% 量37万（缩量40%）
```

**逻辑：** 大阳线是主力建仓信号，次日缩量横盘=主力没有出货。第三天大概率继续上攻。

**操作：** 次日横盘时入场，止损放在大阳线起点下方。

### 2. 板块ETF涨但个股没涨 ⭐⭐

**识别：** 板块ETF+2-3%但个别成分股涨幅<1%

```
例：影视ETF+3.9%但游戏股（同ETF成分）仅+0.5%；中药ETF+2%但华润三九仅+0.5%
```

**逻辑：** ETF涨幅由板块龙头贡献，但龙头涨停封死后资金会找板块内便宜的补涨标的。

**操作：** 找PE最低+涨幅最小的成分股，龙头涨停次日资金溢出时入场。

### 3. 暗吸（小阳线连续+量稳定）⭐⭐⭐

**识别：** 连续5天以上每天+1-2%，成交量完全稳定不放大

### 4. 横盘蓄力突破（2026-08-03新增）⭐⭐⭐⭐

**识别：** 连续≥7天日波幅<3%+量缩均匀 → 某天放量>1.5x突破横盘上沿

```
例：卧龙电驱 7/20-7/30 10天横盘缩量 → 8/3 +8.9%爆发
```

**逻辑：** 主力控盘后测试抛压，横盘越长爆发越猛。是提前量扫描里优先级最高的形态——横盘期入场，爆发当天兑现。

**操作：** 第5-7天横盘时入场，止损放在横盘下沿下方。放量突破后持有。

```
例：云南白药 6连阳，每天+1-2%，量稳定在15-16万
```

**逻辑：** 不是散户行为。每天匀速吃货、不拉涨停吸引注意=机构悄悄建仓。

**操作：** 第5-7根小阳线时入场，止损放在起涨点。

## 致命反例：已经在涨的别追

| 追高形态 | 为什么不买 |
|------|------|
| 今天+7%以上 | 已price in，明天大概率回踩 |
| 近涨停但没封住 | 尾盘回落=追高的人当天被套 |
| 连续2天+5%以上 | 短线获利盘巨大，随时砸 |
| 板块3只涨停 | 高潮日，次日分歧概率>80% |

> ⚠️ 例外：激进追涨模式（见 references/激进追涨模式.md）可放宽涨幅限制，但需用户明确切换模式。

## 执行流程

每轮全局选股分两遍：

**第一遍（快扫）：** ETF排名→板块涨幅。回答"今天什么强"。

**第二遍（提前量——必须在否决前完成）：** 
1. 对排名前10的板块，**先扫成分股PE+形态**（不限PE）
2. PE合理的龙头即使板块高潮也单独评估
3. 找到蓄力形态目标后再判断是否追高
4. 板块否决放在最后——不能否决在成分股扫描之前

> ⚠️ 教训：白酒ETF+3.7%高潮，如果在STEP2直接否决就看不到泸州老窖PE13+73→90涨23%。应该是先看到有泸州老窖这种PE13的龙头，再判断"趋势高潮可以参与"。

## ⚠️ 蓄力形态全市场扫描（2026-07-24 → 2026-08-03修正）

**蓄力形态扫描独立于PE筛选，不限PE。** 每轮全局选股强制跑一遍。

扫描标准（满足任意2条即可给观察仓）：
- 连续≥5天横盘（波幅<5%）+ 缩量
- 60日回撤>25% + 分位<15%
- 前5天有+3%以上阳线 + 近2天缩量横盘

**不要求三条件全齐——差一个条件不是否决理由，而是仓位降低。** 昭衍新药PE73只满足一个条件即涨停，四方差0.1量缩也飞了。

### 板块弱≠个股没机会（2026-08-05新增）

**教训案例：** 巨人网络002558，7/27游戏板块补跌-3%时，个股缩量止跌（量从156万缩到69万，缩55%）+低点23.61→7/29放量+10%反弹，3天+18%。当时按"板块弱不碰"跳过，错失左侧反弹。

**规则：** 即使板块ETF走弱，只要个股满足左侧条件（60日回撤>25% + 分位<15% + 缩量到前日50%以下）就单独评估，不因板块弱势否决个股。缩量止跌是独立于板块的个股信号。
