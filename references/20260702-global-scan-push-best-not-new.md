# 2026-07-02: "不用一直推全新，推最佳" — 多次全局选股的最终修正

## 现象
会话中用户连续4+次要求全局选股。按当时 skill 规则，第3次起开始「换方向」：
1. 防守（止损160644） → 用户执行了
2. 沈阳机床（工业母机） → 未买
3. 紫金矿业（贵金属） → 未买，但这是当日信号最强的标的
4. 五洲新春（机器人） → 用户问了但未买
5. 中国中车（交运设备） → 被用户纠正

**用户纠正："不用一直推全新，推最佳"**

## 根因
Skill 中"连续3次全局选股后必须完全不同"的规则，导致机械地切换方向去追求"不同"，而不是追求"最强"。第4次时推了中国中车（60日20%位+板块资金流入最大），但紫金矿业（60日18%位+99亿成交+贵金属板块#1）当天明显信号更强——只是为了"不同"而换了它。

## 修正

### 核心原则
> **方向的成立由当前市场数据决定，不是由被拒次数决定。**

- 用户没买 ≠ 方向错误（可能只是时机/价位/仓位不合适）
- 用户反复要求选股 = 还在等更打动他的东西 → 不是需要换方向
- 「推最佳」永远优先于「推最新」

### 输出策略调整

```
用户第N次要求全局选股
├─ 第1-2次：正常推荐首选+操作计划
├─ 第3+次：不要机械换方向
│  └─ 重新跑六步法，如果原方向仍最强：
│     ├─ 坚持原方向，换细分/换价位/换标的
│     └─ 输出时强化推荐信心：用PK对比表说明"为什么这个仍然是今天最佳"
│  └─ 如果数据确实变了：
│     └─ 按数据推新方向，但不说"这是换方向"
└─ 核心：宁可重复同一个标的的推荐理由，也不要为了不同而推弱的方向
```

## 与 2026-07-01 修正的关系

| 日期 | 修正 | 侧重点 |
|:---:|:----|:------|
| 07-01 | 第二次全局选股≠必须换方向 | 方向切换的时机判断（同一日内的方向延续性） |
| 07-02 | 不用一直推全新，推最佳 | 第三次+的推荐策略（不是不换，而是推最强的那个） |

两者互补：07-01 解决「什么时候换」，07-02 解决「怎么选」。
