# 左侧埋伏：高潮日预判次日轮动

## 核心逻辑

高潮板块（涨跌比>5:1）次日分歧概率>80%。分歧后资金会流向连续弱势+低位+缩量的板块。高潮日收盘前，提前在低位板块布局=左侧埋伏。

## 触发条件

1. 当日有≥3个板块涨跌比>5:1（高潮信号）
2. 存在连续弱势板块（回撤>15%+分位<10%）
3. 弱势板块出现缩量（量比<0.7x，卖盘枯竭）

## 执行步骤

### 1. 确认高潮板块数
ETF排名TOP8中统计涨跌比>5:1的板块数量。≥3个即可触发。

### 2. 找低位候选
从ETF排名BOTTOM中找出弱势板块，按以下优先级：
- 回撤最深（>20%优先）
- 分位最低（<10%优先）
- 缩量最明显（量比<0.7x优先）

### 3. 验证轮动逻辑
- 低位板块是否有潜在催化？（政策/业绩/周期拐点）
- 板块内是否有PE合理（<50）的龙头？
- 板块ETF今日是否出现"偷偷翻红"信号？（从-1.5%拉回到+0.5%以上）

### 4. 选标的
- 优先板块ETF（分散风险，省心）
- 其次板块内PE最低+今日跌幅最大的龙头（超跌反弹弹性最大）
- **必须检查科创板权限**（688xxx不能买）

## 实例：2026-07-17 半导体左侧埋伏

```
高潮板块: 煤炭/白酒/创新药/食品/电力/计算机 = 6个
低位候选: 半导体（回撤25.8%+分位3%+量缩0.6x）
轮动逻辑: 6个高潮→明天必然分歧→资金找最低位
验证: 半导体ETF盘中-1.5%→尾盘+0.9%（偷翻红）
标的: 芯片ETF 512760（省心）> 个股（PE普遍偏高）
```

## 风险

- 轮动可能延迟1-2天（高潮后不一定立刻轮动）
- 低位板块可能继续阴跌
- 仓位控制在现金10-15%（左侧=试探性仓位）

## ⚠️ 失败模式：防御抱团强化

**2026-07-20~21 实例：** 预测"6个高潮→次日分歧→轮动半导体"。实际：煤炭+5.6%→+5.9%继续涨，半导体-2.2%→-3.9%继续崩。预判完全错误。

**失败根因：** 高潮≠必然分歧。当市场处于系统性避险（科创50连跌），资金持续涌入防御板块形成正反馈——越涨越追，越追越涨。

**识别信号（以下信号出现时放弃左侧埋伏）：**
1. 科创50连续3天放量下跌（科技出清未完）
2. 防御ETF量能不缩反增（不是高潮衰竭，是加速）
3. 中证1000持续跑输上证50（小盘恐慌未消）

**应对：** 放弃左侧，持币等待。轮动逻辑前提是"市场企稳"，不是"跌多了就该涨"。
